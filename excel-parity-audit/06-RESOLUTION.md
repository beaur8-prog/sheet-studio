## 02. 수식 엔진

| ID | 처리 | 검증 |
|---|---|---|
| 1-1 | 산술 변환에서 진짜 빈 셀과 빈 문자열 구분 | 산술·SUM 테스트 |

| 1-4 | 생략 슬롯을 0으로 평가하되 선택 인자의 생략 여부 보존 | COUNTA·AVERAGE·MIN·IF 테스트 |
| 2-1 | COUNT·COUNTA의 직접 오류 인자 포착 | 오류 집계 테스트 |
| 2-2 | 배열 상수의 텍스트를 AVERAGEA·MINA·MAXA 통계에서 제외 | MINA 및 수정된 함수 fixture |
| 3-1 | 날짜 서식의 월 이름과 요일을 Excel 일련번호로 계산 | 일련번호 1·59·60 테스트 |
| 3-2 | 월을 먼저 정규화한 뒤 Excel 일련번호로 일수 가감 | DATE의 1900년 overflow·underflow 테스트 |
| 4-1 | 조건 판정의 blank·빈 텍스트·숫자 텍스트·타입 비교 분리 | 감사의 COUNTIF 행렬 재현 |
| 4-2 | 조회 시 빈 셀과 서로 다른 타입을 건너뜀 | MATCH·VLOOKUP·XLOOKUP·XMATCH 테스트 |
| 4-3 | XLOOKUP 생략 fallback은 `#N/A`; SUMIF의 합계 참조는 조건 범위 크기로 확장 | 생략·확장 테스트 |
| 5-2 | 범위 `:`, 교집합 공백, 괄호 안 합집합 `,`를 참조 연산자로 지원 | INDEX의 동적 끝점·교집합·합집합 테스트 |
| 5-3 | IFERROR가 정상 배열에 오류 fallback을 적용하지 않음 | SUM(IFERROR({1,2},1/0)) 테스트 |
| 5-4 | 참조 스캐너의 시트 비교를 대소문자 무관으로 통일 | 혼합 대소문자 범위 테스트 |

배열 결과의 동적 spill은 계속 미지원입니다. 참조 메타데이터(ROW·ROWS 등)는 셀 값을 읽지 않고 계산해 자기 참조 오류가 생기지 않도록 유지합니다. 기존 테스트 중 SUMIF 크기 불일치, 전치 참조, AVERAGEA 배열 텍스트의 기대값은 이번 수정에 맞춰 바로잡았습니다. AVERAGEA의 텍스트 제외 기준은 [Microsoft 설명](https://support.microsoft.com/en-us/excel/functions/averagea-function)을 참고했습니다. 실제 Excel에서 이번 기대값을 다시 실행한 것은 아닙니다.
