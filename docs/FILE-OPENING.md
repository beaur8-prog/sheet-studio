# 파일 열기와 취소

**0.7.39 개발 버전 — 아직 공개 배포되지 않았습니다.**

파일을 선택하면 형식 확인, 서식·연결 읽기, 셀 해석, 표·차트·피벗 읽기 등 실제 처리 단계를 표시한다. 여러 시트나 CSV 행을 처리하는 구간에서는 확인할 수 있는 개수만 표시한다. 남은 시간을 추측한 백분율은 사용하지 않는다.

**열기 취소** 또는 **Esc**로 파일 해석을 중단할 수 있다. 현재 문서의 값·편집 기록·파일 위치와 기존 복구본은 유지한다. 취소한 문서를 복구본으로 덮어쓰거나 해당 폴더를 현재 저장 위치로 확정하지 않는다. 다음 파일을 다시 열거나 현재 문서 편집을 계속할 수 있다.

읽기를 마친 뒤 **문서 적용 중**에는 취소 버튼이 비활성화된다. 이 단계는 검증된 문서를 화면에 연결하는 구간이다. 큰 문서의 적용·화면 구성에는 짧은 멈춤이 남아 있다. 저장·정렬·전체 계산 등 다른 작업의 취소 기능을 추가했다는 뜻은 아니다.

파일 해석은 별도 작업 스레드에서 수행한다. 취소하면 해석 스레드를 종료하고 읽던 후보 문서를 버린다. 현재 문서의 계산·자동 복구를 맡은 스레드는 유지한다. 취소 표시가 닫힌 뒤 운영체제가 스레드를 완전히 정리하는 데는 추가 시간이 들 수 있다. 문서를 분리해 준비하는 비용 때문에 모든 파일이 더 빨라지는 것은 아니다.

숨긴 시트나 `veryHidden` 시트를 활성 상태로 저장한 파일·이전 복구본은 첫 번째 보이는 시트를 표시한다. 숨긴 상태와 데이터는 바꾸지 않는다. 문서를 적용하지 못하면 기존 문서를 복원하고 파일 열기 오류를 알린다.

파일은 기존처럼 최대 100 MB, XLSM 원본은 15 MB, 기록 셀은 통합 문서 전체 1,000,000개까지 지원한다. 암호화·손상·용량 초과는 현재 문서를 바꾸지 않고 오류로 처리한다. 일반 시작 시 빈 통합 문서를 보여주는 정책과 명시적 **이전 문서 복구**는 유지한다.
