# 자동 필터

데이터 → 정렬 및 필터 → **필터**를 누르면 데이터의 첫 행에 드롭다운 화살표가 생깁니다. 데이터 안의 셀 하나를 선택하면 빈 행·열로 구분된 현재 영역을 추정하며, 여러 행을 선택하면 그 범위를 사용합니다. 머리글 한 행만 선택하면 아래로 이어지는 데이터를 포함합니다. 첫 행이 실제 머리글인지 확인하세요.

- 드롭다운에서 오름차순·내림차순, 값 검색, 모두 선택, 개별 값/빈 셀 선택, 해당 열의 필터 해제를 실행합니다. 확인 전 변경은 취소·Esc·바깥 클릭으로 버릴 수 있습니다.
- 검색은 대소문자를 구분하지 않으며 `*`, `?`, `~` 와일드카드를 지원합니다. 검색 결과를 기존 선택에 추가하는 옵션도 있습니다.
- 텍스트/숫자/날짜에 맞는 조건 메뉴가 열립니다. 두 조건의 AND/OR, 범위 사이, 상위·하위 항목/퍼센트, 평균 초과·미만을 지원합니다. 날짜는 날짜별 목록과 직접 입력 조건을 제공합니다.
- **색 기준 필터**를 펼쳐 **셀 채우기색** 또는 **글자색** 견본을 선택하고 **확인**을 누릅니다. **채우기 없음**과 **자동 (기본 글자색)**도 선택할 수 있습니다. 취소·Esc·바깥 클릭으로 적용 전 선택을 버립니다. 같은 열에서는 값/숫자/날짜 조건과 색 조건 중 하나를 사용하며, 다른 열의 조건과는 함께 적용합니다.
- 색 견본 옆에는 해당 색의 행 수를 표시합니다. 머리글을 제외하고 다른 열의 조건을 통과한 행에서 실제 표시색을 읽으며, 지원되는 조건부 서식의 색과 색이 지정된 빈 셀도 포함합니다. 명시적인 흰색 채우기와 채우기 없음은 구분합니다. 값을 편집하거나 색·조건부 서식을 바꾼 뒤 **다시 적용**하면 현재 색으로 다시 거릅니다. 한 번에 1,000개 색을 표시하며, 더 많은 색은 다른 열 조건으로 범위를 좁힐 수 있습니다.
- 여러 열의 조건은 AND로 결합합니다. 각 열의 목록은 다른 열의 필터를 통과한 값으로 좁혀집니다. 적용된 열에는 깔때기 아이콘이 표시됩니다.
- **지우기**는 조건을 없애고 화살표를 남깁니다. **필터**를 다시 누르면 조건과 화살표를 모두 제거합니다. 셀 편집 후 **다시 적용**하면 저장된 조건으로 다시 거릅니다.
- 필터 범위 밖의 행은 숨기지 않습니다. 필터 상태에서 정렬하면 보이는 레코드끼리 이동하고 제외된 레코드는 제자리에 남습니다. 빈 값은 양 방향 정렬 모두 마지막입니다.
- 방향키는 숨겨진 행을 건너뛰며, 복사와 인쇄는 필터로 제외한 행을 생략합니다. SUBTOTAL은 필터 제외 행을 집계하지 않습니다. 일반 SUM은 전체 범위를 계산합니다.
- Windows `Ctrl+Shift+L`, macOS `⌘+Shift+L`로 켜고 끌 수 있습니다. 필터 열에서 `Alt+↓`로 메뉴를 열 수 있습니다.
- 시트별 조건·범위·현재 숨김 행은 자동 저장, JSON, 실행 취소/다시 실행으로 복원됩니다. 행·열 삽입/삭제 시 범위가 이동하며 머리글 행을 삭제하면 자동 필터가 제거됩니다.

## Excel 파일과 검증

XLSX에 실제 OOXML `autoFilter`, 조건, 날짜 그룹, 숨김 행과 정렬 표시를 저장합니다. 0.7.16 개발 버전부터 색 조건은 `colorFilter`와 스타일의 `dxf`로 저장하며, 기존 조건부 서식 스타일 참조를 유지합니다. RGB·테마/명암·인덱스 색을 셀과 필터 기준에 같은 방식으로 해석합니다. 해석할 수 없는 색 스타일 참조는 미지원으로 안내하고 저장된 숨김 행을 보존합니다. Excel이 만든 일반 범위 필터도 읽습니다. XLSM의 수정은 기존 Windows Excel 연결을 통해 적용하며 원본 파일을 직접 변경하지 않습니다. 날짜 선택은 실제 Excel 표시 문자열로 변환해 전달합니다.

설치된 Excel 16.0 build 19127의 별도 시험 문서에서 16개 조건 사례의 표시 행과 SUBTOTAL 결과를 수집했습니다. 내보낸 16개 XLSX를 Excel에서 열고 필터를 다시 적용해 같은 결과를 확인했습니다. 날짜 목록/조건의 XLSX 재적용, 필터 상태에서의 정렬, XLSM 필터 저장·제거도 별도로 검증했습니다. 이 변경은 소스 구현과 Excel COM 동작 비교를 사용했으며 필터 관련 네이티브 함수를 역컴파일했다는 의미는 아닙니다.

참고한 Microsoft 공식 안내: [범위 또는 표 필터링](https://support.microsoft.com/en-us/excel/get-started/filter-data-in-a-range-or-table-in-excel?re=true), [필터 지우기/제거](https://support.microsoft.com/en-us/excel/clear-or-remove-a-filter), [다시 적용](https://support.microsoft.com/en-us/excel/reapply-a-filter-and-sort-or-clear-a-filter).

0.7.16의 색 필터는 앱의 화면·조건 결합·취소·실행 취소·재적용·재시작, XLSX 왕복, Windows 저장 계획을 검사했습니다. 실제 Windows Excel/VBA 실행을 추가 검증한 것은 아닙니다. 형식과 저장 계획은 Microsoft의 [OOXML ColorFilter](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.colorfilter?view=openxml-3.0.1) 및 [AutoFilter 연산자](https://learn.microsoft.com/en-us/dotnet/api/microsoft.office.interop.excel.xlautofilteroperator?view=excel-pia)를 참고합니다.

## 범위와 남은 차이

아이콘 필터, 상대 날짜(이번 주 등), 날짜의 연·월 트리, 고급 필터, 슬라이서, 여러 구조화된 Excel 표별 독립 필터는 아직 지원하지 않습니다. 가져온 일반 범위의 미지원 조건은 숨김 상태를 표시하지만 편집/다시 적용을 막고 안내합니다. 이 상태의 XLSX 내보내기는 먼저 지우기를 요구합니다. XLSM의 손대지 않은 원본 조건은 Excel에 남깁니다.

원본의 여러 글자색이 섞인 리치 텍스트·지원하지 않는 조건부 서식/패턴·그라데이션 채우기의 색은 현재 화면에서 재현하는 범위로 제한됩니다.

0.7.17 소스에서 한 필터의 데이터 행은 최대 1,000,000개, 한 번의 정렬은 최대 1,000,000셀입니다. 문서 전체 셀 한도도 적용하며 필터 항목 계산·적용·정렬을 작업 스레드에서 수행합니다. 드롭다운은 한 번에 10,000개 값을 표시하며 검색은 전체 값에서 수행합니다. Excel 외부 연결·보호된 시트·혼합 표시 형식·수동 숨김과 필터 숨김의 모든 조합, 잘라내기/붙여넣기·자동 합계의 모든 Excel 특수 규칙을 재현하지는 않습니다. 플랫폼별 실행·패키지 검증 내역은 [검증 기록](../VALIDATION.md)을 참고하세요.
