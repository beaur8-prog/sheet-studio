# 데이터 유효성 검사

**0.7.39 개발 버전 — 아직 공개 배포되지 않았습니다.**

셀 범위를 선택하고 **데이터 → 데이터 유효성 검사**를 누른다. 목록·정수·소수·날짜·시간·텍스트 길이·사용자 수식의 조건을 작성하거나 기존 규칙을 편집할 수 있다. 적용 범위는 `A1` 또는 `A1:B10`처럼 입력한다. `A1:A1048576` 같은 큰 범위도 셀을 모두 만들지 않고 규칙만 기록한다.

## 조건 작성

| 허용 값 | 입력 예 |
|---|---|
| 목록 | `예,아니오` 또는 `=$H$1:$H$5`. 이름·다른 시트·수식도 `=`로 시작한다. |
| 정수·소수 | 비교 조건과 `1`, `10` 또는 `=$H$1` 같은 경계값·수식 |
| 날짜 | `2026-01-01`부터 `2026-12-31`까지 또는 `=TODAY()` |
| 시간 | `09:00`부터 `18:00`까지 또는 `=TIME(9,0,0)` |
| 텍스트 길이 | `작거나 같음`, `10` |
| 사용자 수식 | `=AND(ISNUMBER(A1),A1>0)`. TRUE 또는 0이 아닌 숫자이면 허용 |

상대 참조는 적용 범위의 왼쪽 위 셀을 기준으로 한다. 기존 `B2:B10` 규칙이 `A2`를 참조할 때 `B5:B7`을 선택해 편집하면 `A5`가 표시된다. 선택한 일부를 바꾸거나 **규칙 지우기**를 눌러도 나머지 셀의 규칙과 참조 의미를 유지한다. 적용·삭제는 한 번의 실행 취소로 되돌린다. 이미 들어 있는 값은 규칙을 만들 때 변경하지 않는다.

목록을 직접 입력할 때는 쉼표·줄바꿈으로 항목을 나누며 빈 항목은 생략한다. 항목 자체에 쉼표가 있거나 목록이 255자를 넘으면 셀 범위를 참조한다. 새 조건 수식은 255자, 제목은 32자, 안내·오류 내용은 255자까지 지원한다. 가져온 더 긴 규칙은 편집하지 않으면 보존한다.

## 입력 안내와 오류 알림

**입력 안내**를 켜면 셀 선택 시 제목·설명이 나온다. 다른 셀을 선택하면 해당 안내로 바뀌며 Esc로 숨길 수 있다. **오류 알림**은 중지·경고·정보 중 선택한다. 중지는 올바른 값으로 수정해야 입력할 수 있고, 경고·정보는 확인 후 계속 입력할 수 있다. 알림을 끄면 조건과 목록은 유지하면서 잘못된 값도 입력할 수 있다.

**모든 값**과 입력 안내를 함께 쓰면 형식을 제한하지 않고 설명만 표시한다. XLSX에는 표준 `none` 유형으로 저장한다. 오류 알림 플래그가 남아 있는 가져온 `none`도 자유롭게 입력할 수 있으며, 이전 개발본의 비표준 `any` 표기는 저장할 때 `none`으로 바로잡는다. [OOXML 유형 정의](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.datavalidationvalues)를 따르며 원문 셀 값은 바꾸지 않는다.

직접 입력 시 검사한다. Excel의 문서화된 정책과 같이 붙여넣기·자동 채우기·수식 결과 변경은 자동으로 막지 않는다. 창의 **현재 값 검사**는 현재 문서에 적용된 규칙으로 기존 입력을 확인한다. 불일치와 확인할 수 없는 수식을 구분하며 값은 바꾸지 않는다. 검사 범위 안에 기록된 비어 있지 않은 셀 중 최대 100,000개를 검사하고 결과는 처음 100개를 표시한다. 빈 셀과 별도 셀 기록이 없는 배열 결과는 제외한다. 창에서 수정 중인 규칙은 먼저 적용한 뒤 검사한다.

날짜·시간 서식 또는 날짜·시간 입력 규칙이 있는 셀에서는 명확한 `YYYY-MM-DD`, `HH:MM[:SS]` 입력을 숫자 날짜·시간으로 처리한다. 1900/1904 날짜 기준을 보존한다. 일반·텍스트 셀의 날짜처럼 보이는 식별자는 자동 변환하지 않는다. 국가별 `11/5/26` 해석, AM/PM, 자연어 날짜는 지원하지 않는다.

## 보존 범위와 제한

- XLSX와 앱 문서는 규칙·입력 안내·오류 종류·목록 표시·범위를 유지한다. 행·열 삽입과 시트 이름 변경도 기존 참조 갱신을 사용한다.
- 보호된 시트, 피벗 결과, XLSM의 규칙 작성은 차단한다. XLSM 규칙은 Excel에서 바꾸거나 XLSX 사본을 다시 열어 편집한다.
- 아직 셀 복사·자동 채우기에서 규칙 자체를 복제하지 않는다. 필요한 대상 범위에 규칙을 적용한다. 기존 대상 규칙은 유지한다.
- 지원하지 않는 규칙 수식은 확인 불가로 알린다. VBA·실제 Excel 실행 검증을 의미하지 않는다. 실제 Windows/Mac Excel의 규칙 편집·복구 경고와 IME 조작은 별도 검증 대기다.
