# 인쇄와 PDF — 0.7.31 개발

**파일 → 인쇄 / PDF**, **페이지 레이아웃 → 인쇄 / PDF**에서 출력합니다. 운영체제 인쇄창에서 PDF 저장을 선택할 수 있습니다. 공개 0.7.29과 개발 0.7.31의 기능은 [README](../README.md)에서 구분합니다.

## 페이지 설정

**페이지 레이아웃 → 페이지 설정…**을 엽니다. 적용은 한 번에 실행 취소할 수 있고, 취소하면 원본을 유지합니다.

| 탭 | 설정 |
|---|---|
| 페이지 | A3·A4·A5·Letter·Legal·JIS B5, 가로/세로, 백분율·가로/세로 페이지 맞춤, 시작 페이지 번호·진행 순서 |
| 여백 | 상하좌우와 머리글·바닥글 위치(mm) |
| 인쇄 영역 | 하나 또는 여러 셀 영역, 반복할 행·열, 눈금선 |
| 머리글/바닥글 | 왼쪽·가운데·오른쪽 텍스트와 필드, 기본/첫/짝수 페이지 구분, 배율과 여백에 맞춤 |

페이지 맞춤의 가로/세로 페이지 수 `0`은 해당 방향의 길이를 제한하지 않습니다. 맞춤은 수동 페이지 나눔을 무시합니다. 반복 제목이 차지하는 공간도 페이지 수에 포함합니다. 저장된 수동 나눔은 백분율 모드에서 적용합니다.

머리글 글상자를 선택한 뒤 페이지·전체 페이지·시트 이름·파일 이름·날짜·시간 버튼을 눌러 넣습니다. `{페이지}` 같은 표시를 직접 입력해도 됩니다. 첫/짝수 페이지를 다르게 설정했다면 **편집할 페이지**에서 해당 내용을 입력하세요. 가져온 글꼴·색·크기 등은 같은 구역의 텍스트를 바꾸지 않으면 유지합니다. 지정 공간을 넘는 머리글·바닥글은 잘린 채 인쇄하지 않고 수정을 안내합니다.

시작 페이지 번호는 `{페이지}`만 바꾸며 `{전체 페이지}`는 실제 출력 쪽 수입니다. 예를 들어 4쪽을 3번부터 매길 때 앞의 2쪽까지 전체 수에 넣으려면 `{페이지} / {전체 페이지}+2`로 입력합니다. 그러면 `3 / 6`부터 `6 / 6`까지 표시됩니다. [Excel의 시작 번호·전체 수 조정 규칙](https://support.microsoft.com/en-gb/excel/insert-page-numbers-on-worksheets)을 따릅니다.

XLSX로 저장하고 다시 열어도 설정을 유지합니다. XLSM의 문서 설정 변경은 Excel 또는 XLSX 사본을 사용하세요. 인쇄창에서 이번 출력의 방향 등은 선택할 수 있습니다.

## 대상과 차트·이미지 배치

- **현재 시트**는 저장된 인쇄 영역을 사용합니다. 여러 영역은 별도 페이지로 나뉘며 영역 밖 값·개체는 포함하지 않습니다. **저장된 인쇄 영역 사용**을 해제하면 현재 사용 영역과 인쇄 대상 개체의 범위를 사용합니다.
- **선택 영역**은 저장 인쇄 영역과 반복 제목을 무시합니다. 선택에 걸친 개체는 해당 부분만 출력합니다.
- **시트에 놓인 위치 그대로**는 차트·이미지를 셀 위의 위치에 표시합니다. 페이지 경계를 넘으면 부분별로 나누고, 표와 함께 같은 배율로 조정합니다. 반복 제목 때문에 차트 자체가 매 페이지 복제되지는 않습니다.
- **셀 뒤에 개체별 페이지**는 셀 표 다음에 차트·이미지를 각각 한 페이지로 출력합니다. 이 방식은 셀 인쇄 영역 밖의 개체도 포함합니다.
- **차트만**은 셀 영역과 관계없이 각 차트를 한 페이지에 출력합니다. 명시적으로 차트만 출력하면 원본의 시트와 함께 인쇄 여부와 관계없이 선택한 차트들을 포함합니다.

차트·이미지 포함 여부를 각각 선택할 수 있습니다. 시트 출력은 가져온 개체의 ‘시트와 함께 인쇄 안 함’ 표식을 따릅니다. 인쇄창의 선택은 이번 출력만 바꾸며 문서의 설정을 수정하지 않습니다.

## 출력 내용과 한계

필터·수동 숨김, 행 높이·열 너비, 병합, 숫자 표시 형식, 표·셀·조건부 서식과 현재 계산 결과를 적용합니다. 페이지를 넘는 병합 내용은 시작 조각에서만 표시합니다. 직접 계산하지 못하는 수식의 유효한 원본 캐시를 쓸 때는 안내하며, 오래된 값을 새 계산값으로 출력하지 않습니다.

한 번에 원래 영역 합계 **20,000셀**, 반복 제목 포함 **100,000셀**, 최대 **500페이지**입니다. 개체 조각은 **2,000개**, 반복된 개체 HTML은 **32,000,000자**로 제한합니다. 너무 큰 반복 제목·셀·개체 분량은 영역·배율을 조정하거나 차트만 출력하도록 안내합니다. 잘못된 인쇄 참조를 전체 시트로 자동 대체하지 않습니다. 지원하지 않는 용지는 안내 후 이번 출력에서 A4를 사용하고 원래 파일 설정은 유지합니다.

단순 PNG/JPEG/GIF/WebP 이미지를 출력합니다. 머리글 그림·원본 경로, 자르기·회전/효과가 있는 그림과 미지원 도형, 행·열 주소 머리글, 흑백·초안, 사용자 용지와 모든 프린터별 설정은 완전히 반영하지 않습니다. 지원하지 않는 원본 정보의 파일 보존과 화면/인쇄 재현은 서로 다른 범위입니다. 글꼴 대체·줄바꿈·드라이버에 따라 실제 Excel과 차이가 날 수 있으며 이번 작업에서 Microsoft Excel을 새로 실행한 비교는 수행하지 않았습니다.

## 검증

인쇄 설정의 반복 XLSX 왕복, 여러 인쇄 영역·특수문자 시트 이름·제목/숨김/나눔/맞춤·병합·한도를 단위 검사합니다. 실제 격리 앱에서 페이지 설정 적용/취소/실행 취소, 저장·재열기, 시트 위치/개별 페이지/선택/차트 전용 출력과 오래된 캐시를 확인합니다.

표·차트·그림을 두 축으로 나눈 4페이지 PDF와 가로 한 페이지 맞춤 PDF를 생성해 좌표·페이지 수·머리글/바닥글을 검사하고 렌더링합니다. 프린터 호출은 테스트에서 가로채 실제 인쇄 작업과 사용자 프린터 설정을 바꾸지 않습니다. [상세 검증](CORE-FIVE-HOUR-20261031.md)을 참조하세요.
