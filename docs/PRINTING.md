# 인쇄와 PDF

0.7.30 개발 버전은 **파일 → 인쇄 / PDF**, **페이지 레이아웃 → 인쇄 / PDF**에서 출력한다. 운영체제 인쇄창에서 PDF 저장을 선택할 수 있다.

## 파일에서 읽어 적용하는 설정

- 현재 시트의 인쇄 영역. 여러 영역은 서로 다른 페이지로 출력한다. 값이 없는 셀도 지정한 영역에 포함되며 영역 밖의 값은 포함하지 않는다.
- 각 페이지에 반복할 행과 열. 필터·수동 숨김을 적용한다.
- A3·A4·A5·Letter·Legal·JIS B5 용지, 가로/세로 방향, 상하좌우 여백.
- 백분율 배율, 지정 페이지 수에 맞춤, 수동 가로/세로 페이지 나눔, 아래로 진행/옆으로 진행 순서. 페이지 맞춤을 사용하면 Excel처럼 수동 나눔을 무시한다.
- 행 높이·열 너비, 병합, 표시 형식, 표·셀·조건부 서식과 현재 계산 결과. 페이지 경계를 넘는 병합 내용은 시작 조각에서만 표시한다.

**저장된 인쇄 영역 사용**을 해제하면 현재 시트의 사용 영역을 출력한다. **선택 영역**은 저장된 인쇄 영역과 반복 제목을 무시한다. **차트만**은 셀 인쇄 영역과 관계없이 차트를 출력한다. 인쇄창의 방향·눈금선·영역 사용 여부는 이번 출력에 적용하며 파일을 수정하지 않는다.

## 한계와 다음 작업

한 번에 원래 영역 합계 20,000셀, 반복 제목을 포함한 출력 100,000셀, 최대 500페이지다. 지나치게 큰 반복 제목이나 한 페이지보다 큰 셀은 범위를 줄이도록 안내한다. 지원하지 않는 용지 크기는 안내와 함께 이번 출력에서 A4를 사용하며 원래 파일 설정은 보존한다. 잘못된 인쇄 참조를 전체 시트 출력으로 자동 대체하지 않는다.

차트와 이미지는 셀 뒤에 이어서 인쇄한다. 원래 시트 좌표에 겹치는 배치, 머리글·바닥글/그림, 행·열 주소 머리글, 흑백·초안 옵션, 사용자 정의 용지와 모든 프린터별 설정은 아직 출력에 완전히 반영하지 않는다. 원본 정보의 XLSX 보존과 앱에서의 동일한 출력은 서로 다른 지원 범위다. 파일에서 가져온 페이지 설정을 편집하는 전용 UI도 후속 작업이다.

글꼴 대체, 줄 바꿈과 프린터 드라이버에 따라 실제 Excel 출력과 차이가 있을 수 있다. 현재 환경에서는 Microsoft Excel을 새로 실행한 비교를 수행하지 않았다.

## 검증

`tests/print-layout.test.mjs`는 Excel 인쇄 설정이 있는 합성 XLSX의 3회 왕복, 영역 밖의 먼 셀 제외, 불연속 영역, 특수문자 시트 이름, 반복 제목/숨김/나눔/맞춤, 병합 경계와 제한을 확인한다.

`tests/ui-print-layout.mjs`는 별도 앱 프로필에서 파일을 열고 실제 작업 스레드의 인쇄 문서를 만든다. 4페이지 표의 반복 행·열, 각 표의 페이지 크기 내 배치, 수식 결과와 원본 불변, 선택 출력과 영역 무시를 검사한다. 프린터 호출은 테스트에서 가로채므로 실제 인쇄 작업이나 사용자 프린터 설정을 변경하지 않는다. 생성한 PDF는 별도로 페이지 수와 렌더링 결과를 확인한다.
