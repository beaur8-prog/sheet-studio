## 1. 데이터 유효성 규칙 작성 (T02)

0.7.38 검증 패키지에서 데이터 탭에 규칙 작성 명령이 없음을 확인했다. 작성 창을 추가해 목록·정수·소수·날짜·시간·텍스트 길이·사용자 수식을 작성·편집하고, 입력 안내와 중지/경고/정보를 설정한다. 부분 범위 교체·삭제 시 기존 범위를 직사각형으로 나누고 상대 수식 기준점을 옮겨 다른 셀의 의미를 보존한다. 전체 열에 규칙을 설정해도 셀을 모두 생성하지 않는다.

검증: 8개 단위 시나리오, 실제 앱 작성·목록 선택·오류 수정/경고 취소·계속 입력·상대 참조 미리 채움·부분 삭제·실행 취소/다시 실행·행 삽입·XLSX 저장/재열기·작은 화면. 붙여넣기는 Excel 공식 정책에 맞게 입력 경고를 우회하는 기존 동작을 유지하고, **현재 값 검사**로 불일치를 별도 확인한다. 검사창은 읽기 전용이며 조건 불일치/확인 불가, 검사·표시 한도를 명시한다.

아직 규칙 자체를 셀 복사·채우기로 복제하는 기능은 미완료다. 보호 시트·피벗·XLSM 규칙 작성은 차단한다. 가져온 알 수 없는 속성·선택 범위 밖 규칙은 보존한다. [사용법·제한·공식 근거](DATA-VALIDATION.md).

## 2. 날짜/시간 입력의 자료형 (E01/F04/T02)

0.7.38 패키지에서 날짜 서식의 A1에 `2026-11-05`를 입력하면 숫자 날짜 46331이 아니라 문자열이 되는 것을 동일 UI 시나리오에서 재현했다. 날짜·시간 서식 또는 해당 유효성 규칙이 있는 셀의 명확한 ISO 날짜·24시간제 시각을 숫자로 저장하고, 필요한 일반 서식에는 날짜/시간 표시를 붙인다. 일반·텍스트 목적지와 따옴표·수식의 종류는 보존한다. 일반 셀의 날짜처럼 생긴 식별자를 일괄 변환하지 않는다.

검증: 4개 단위 시나리오에서 문서화된 2011-07-05=40729, 1900-02-29 특례, 1462일 차이, DST 날짜·잘못된 날짜/시각, 초·밀리초, 텍스트·값 붙여넣기 보존을 확인했다. 실제 앱은 1900/1904 각각 서식 입력·유효성 입력·오류 재시도·계산 함수·XLSX 재열기를 통과했다. 실제 Excel 입력 지역 설정 비교는 대기다.
