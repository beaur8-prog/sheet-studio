# 차트 — 0.7.29 개발

0.7.29 개발 기능을 포함한 안내입니다. 현재 공개 0.7.28과 이번 검증을 구분하며 [개선 기록](EXCEL-IMPROVEMENTS.md)에 재현·수정·검사 범위를 남깁니다.

## 값 축과 개체 배치

차트 **설정 → 축 범위·눈금·표시 형식**에서 주 값 축·분산/거품형의 가로 값 축·보조 값 축을 편집합니다. 최소/최대값·주 눈금 간격을 비우면 자동이며, 표시 코드를 지정하거나 **자동으로 재설정**할 수 있습니다. 로그 밑은 2~1000이며 0 이하의 값은 로그 축에 표시하지 않습니다. 백분율 축은 1=100%로 입력합니다. 값 순서와 주 눈금선도 조정합니다.

자료가 지정한 범위를 벗어나면 그래프 영역에서 잘라 표시하며 원래 자료는 유지합니다. 가져온 값 축 설정도 미리 보기에 반영합니다. 아직 모든 범주/날짜 축 간격·교차점·표시 단위를 편집하거나 동일하게 그리지는 않습니다.

**셀 변경 시 위치**는 셀과 함께 이동·크기 조절, 이동만, 위치/크기 고정 중 선택합니다. 새 차트는 셀과 함께 이동·크기 조절합니다. 원래 Excel 앵커의 동작을 유지하고 행열 삽입/삭제·너비/높이·수동 숨김을 반영합니다. 직접 차트를 움직인 후 저장해도 이 동작을 유지합니다. XLSM의 축/배치 설정 편집은 Excel 또는 XLSX 사본을 사용하세요.

## 데이터와 인쇄

필터·수동 숨김을 기본으로 반영하며 **숨겨진 행·열의 데이터도 표시**로 포함할 수 있습니다. 실제 계산 오류를 이전 숫자 캐시로 바꾸지 않습니다. 지원하지 않는 수식에 원래 캐시를 사용하는 경우에는 표시합니다. 혼합 누적은 유형·축별로 계산하고, 거품 크기는 같은 차트에서 공통 기준으로 비교합니다. 원형의 조각과 범례 색·백분율, 날짜 간격과 숫자 서식을 보강했습니다.

가져온 차트 전용 시트의 순서·활성 상태·이름·참조와 원본 XML을 유지합니다. 지원하는 차트는 설정을 편집하고 인쇄할 수 있습니다. 셀 편집은 일반 워크시트에서 합니다. 일반 이미지·도형의 연결 파트도 보존하며 단순 래스터 이미지는 표시합니다. 자르기·회전/효과가 있는 이미지와 미지원 도형은 원본을 유지하고 미리 보기 제한을 알립니다.

**페이지 레이아웃 → 인쇄 / PDF**에서 현재 시트·선택 영역·차트만 중 대상을 고르고 방향·눈금선·차트/이미지 포함을 정합니다. 현재 값과 서식을 작업 스레드에서 구성하며 차트·이미지는 셀 뒤에 이어서 배치합니다. Excel의 셀 위 차트 겹침·모든 프린터/머리글 배치를 그대로 복제한 출력은 아닙니다.


**삽입 → 모든 차트**에서 유형을 선택합니다. 0.7.11부터 첫 행·첫 열이 숫자이면 값으로 포함합니다. 문자 제목 행은 계열 이름, 문자 항목 열은 가로축 이름으로 자동 구분합니다. 제목이 없는 숫자 표와 숫자 한 열도 선택해 차트를 만들 수 있습니다. 연도·날짜·번호처럼 숫자를 항목명으로 쓰려면 차트 **설정 → 첫 열을 항목 이름으로 사용**을 켜세요. 숫자로 된 제목 행은 **첫 행을 계열 이름으로 사용**을 켭니다. 이 설정은 차트를 저장하고 다시 열어도 유지합니다. 차트 오른쪽 위 **설정**에서 제목·범례·데이터 레이블·축 제목을 바꾸고, 테두리의 8개 조절점으로 크기를 바꿉니다. 이동·크기 변경·설정 변경은 실행 취소할 수 있습니다.

## 세로 막대형의 항목 표시 (0.7.15 개발)

한 계열의 세로 막대형은 항목 이름을 각 막대 바로 아래 가로축에 표시하고, 모든 막대에 같은 색을 사용하며 중복 범례를 생략합니다. 막대 폭과 항목 사이 간격을 조정하고 긴 이름은 실제 글자 폭에 맞춰 두 줄까지 표시합니다. 더 긴 이름은 말줄임표와 전체 이름 툴팁을 제공합니다.

예를 들어 첫 행이 `커피, 차, 주스, 물`, 둘째 행이 `120, 90, 150, 80`이면 자동 방향에서 한 계열의 막대 네 개로 표시합니다. 여러 관측 행이 있는 표와 명시적으로 선택한 행·열 방향은 유지하며, 여러 계열의 색과 범례는 계속 구분합니다. 기존 차트에 열 방향이 저장되어 있으면 설정에서 **자동**을 선택해 이 해석을 적용할 수 있습니다. 새로 만든 한 계열 세로 막대형의 XLSX와 Windows 저장 계획도 중복 범례를 생략합니다.

## 가로 한 줄의 값과 계열 방향 (0.7.14 개발)

`A1:D1`의 `10, 20, 30, 40`은 네 개의 점을 가진 **한 계열**로 읽습니다. 원형은 네 조각, 도넛형은 네 조각으로 나뉜 한 고리, 꺾은선은 네 점을 잇는 선이 됩니다. 세로 한 줄도 동일하게 처리합니다. 차트 삽입/설정의 **데이터 계열 방향**에서 행 기준(가로 값)·열 기준(세로 값)을 선택할 수 있고 방향은 앱 문서에 저장됩니다. 기존의 한 줄 앱 차트도 수정된 해석을 사용하며, 가져온 Excel 차트는 명시적인 계열 참조를 유지합니다.

행 기준에서는 첫 열을 계열 이름, 첫 행을 항목 이름으로 사용할 수 있습니다. 열 기준에서는 첫 행이 계열 이름, 첫 열이 항목 이름입니다. 숫자로 된 첫 값은 자동으로 제외하지 않습니다. 원형은 첫 계열 하나의 모든 값을 사용하고 도넛형은 모든 계열을 각각 고리로 표시합니다. 원형의 여러 계열은 삽입/설정 화면에서 안내합니다.

분산형은 X·Y 두 행 또는 두 열을 연결합니다. 값이 한 줄뿐이면 Y값으로 쓰고 X값은 `1, 2, 3, 4…`로 지정합니다. 거품형은 첫 행/열의 X값 다음에 **Y값·크기 쌍**이 필요합니다. 값 네 개만 있는 한 줄을 선택하면 임의의 한두 거품을 그리는 대신 필요한 자료를 안내합니다. 거품 네 개를 만들려면 각 항목의 X·Y·크기를 담은 `4행×3열` 또는 행 기준의 `3행×4열`을 선택하세요. 명시적인 X값이 비어 있거나 거품 크기가 0이면 그 점을 그리지 않습니다.

원형·도넛형 범례는 좁은 차트에서도 줄을 바꿔 네 항목 모두 표시합니다. 최대 세 줄을 넘는 항목은 ‘외 N개 항목’으로 표시합니다. 0값은 원의 조각을 만들지 않습니다. 영역·방사형에도 데이터 점과 값 툴팁을 표시합니다. Windows Excel 저장 계획과 XLSX도 동일한 행·열 참조를 사용합니다. 실제 Windows Excel/VBA 실행 검증을 추가로 수행한 것은 아닙니다.

## 새 차트 만들기

| 유형 | 구현한 변형 / 데이터 구성 |
|---|---|
| 세로 막대형 | 묶은형, 누적, 100% 누적 |
| 가로 막대형 | 묶은형, 누적, 100% 누적 |
| 꺾은선형 | 일반, 누적, 100% 누적 |
| 영역형 | 일반, 누적, 100% 누적 |
| 원형 | 첫 번째 값 계열 |
| 도넛형 | 여러 값 계열을 여러 고리로 표시 |
| 분산형 | 첫 열 X값, 나머지 열 Y값; 표식으로 표시 |
| 거품형 | 첫 열 X값, 이후 Y값·크기 열의 쌍 |
| 방사형 | 여러 계열 |
| 혼합형 | 막대 + 마지막 계열 꺾은선, 마지막 계열의 보조축 선택 |

10개 유형, 18개 기본 조합을 제공합니다. 여러 계열과 음수 값, 셀 수정 후 갱신을 지원합니다. XLSX에는 그림 대신 실제 DrawingML 차트를 기록하므로 Excel에서 계열과 유형을 편집할 수 있습니다. Windows XLSM 저장 경로는 설치된 Excel에서 차트를 생성·수정·삭제합니다.

## 기존 Excel 차트 가져오기

워크시트 안에 삽입된 차트의 계열 참조, 값 캐시, 제목, 범례, 기본 색상과 위치를 읽습니다. 지원하는 유형은 앱에서 미리 보고, 같은 통합 문서의 셀 값을 바꾸면 갱신합니다. 시트 이름 변경과 행·열 삽입/삭제 시 지원하는 A1 참조를 조정합니다. 지원 이름 정의는 원래 수식을 유지하면서 범위로 해석하며, 해석할 수 없는 수식은 원본에 저장된 차트 값으로 표시합니다.

가져온 차트는 원본 차트 XML, 직접 연결된 스타일·색·이미지 등의 패키지 파트와 관계를 보관합니다. XLSX로 다시 저장할 때 이 자료를 사용하며, 명시적으로 바꾼 제목·범례·레이블·축 제목과 데이터 참조/캐시를 반영합니다. 크기와 위치를 바꿔도 원래 셀 배치 동작을 유지하도록 앵커를 갱신합니다. JSON 저장에도 원본 차트 자료가 포함됩니다.

가져온 차트의 **유형·배치·데이터 범위·첫 행/첫 열 사용·보조축**을 변경하려면 **새 차트로 변환**을 선택해야 합니다. 변환하면 기존의 고급 서식을 제거하고 앱이 지원하는 차트를 만듭니다. XLSM에서 가져온 차트를 다른 시트로 복제한 경우에는 새 차트로 변환하거나 XLSX로 저장해야 합니다.

## 미리 보기와 호환성 한계

- 3D 막대·꺾은선·영역·원형은 2D로 미리 봅니다. 원본 XML의 3D 설정은 유지합니다.
- 주식형·표면형 및 ChartEx 기반 최신 차트는 원본 보존 안내 영역으로 표시합니다. 새로 만들거나 앱에서 실제 모양을 그리는 기능은 아직 없습니다.
- 추세선, 오차 막대, 모든 범주/날짜 축 옵션, 다단계 범주, 개별 데이터 레이블 서식, 효과·테마·3D 조명 등을 동일하게 그리는 기능은 없습니다. 직접 수정하지 않은 원본 차트 XML에는 해당 설정이 남습니다.
- 외부/OLAP PivotChart와 통합 문서 외부 연결의 모든 종속 관계는 지원 범위가 아닙니다. 파일 전체를 그대로 보존하는 범용 OOXML 편집기는 아닙니다.
- 원형의 음수는 절댓값으로 표시하고 방사형은 음수와 0을 다른 반지름으로 구분합니다. 빈 값, 누적 음수, 복합 차트와 고급 서식의 모든 Excel 표시 규칙을 재현하지는 않습니다.
- 글꼴별 열 너비 환산은 근사치입니다. 원본과 앱의 차트 위치/크기가 약간 다를 수 있습니다.
- 새 범위는 계열당 최대 10,000개 값·32개 값 행/열입니다. 미리 보기는 계열당 1,000개 점과 가져온 그룹당 32개 계열로 제한합니다. 큰 원본 참조의 캐시는 잘라 덮어쓰지 않습니다.
- 가져오기는 통합 문서당 200개 차트, 차트당 원본 파트 합계 16 MB·연결 파트 250개 제한이 있습니다. 전체 입력/JSON은 100 MB, XLSM 원본/결과는 15 MB 제한입니다.

Windows와 macOS는 같은 차트 렌더링·XLSX 코드를 사용합니다. 플랫폼별 실제 실행·패키지 검증 내역은 아래 검증 기록을 참고하세요. VBA 실행 및 VBA를 유지하는 XLSM 수정 저장은 Windows Excel 연결 전용입니다.

## 검증

0.7.29의 새 검증은 [작업 기록](EXCEL-IMPROVEMENTS.md)과 [검증 기록](../VALIDATION.md)을 참고하세요. 아래 실제 Windows Excel 실행 항목은 이전 버전의 검증 이력이며 이번 작업에서 Excel/VBA를 다시 실행한 것은 아닙니다.

- 단위 검사: 18개 조합의 XLSX·JSON 왕복, 여러 계열과 참조·값 갱신, 제목·범례·축 제목·레이블, 반복 저장, 이름 정의, 알 수 없는 차트와 연결 이미지 보존.
- 실제 Windows Electron: 10개 유형 삽입, 설정, 크기 조절, 저장/열기, 셀 변경, 명시적 변환, 실행 취소 및 재시작.
- 설치된 Windows Excel: 새 18개 조합을 열어 차트와 계열 값 확인 후 재저장. Excel이 만든 차트 13개(3D·표면형 포함)의 가져오기/재저장 검사.
- Windows Excel XLSM: 기존 차트 제목·크기·범례 수정, 18개 조합 생성, 삭제, 원본 파일 불변 검사. VBA 매크로 실행 성공 검사는 아닙니다.
- ChartEx는 합성 OOXML 자료의 파트·관계 보존을 검사했습니다. 로컬 Excel의 최신 차트 생성 호출이 거부되어 실제 최신 차트 파일 전체의 Excel 왕복은 검증하지 못했습니다.

정확한 실행 결과는 [검증 기록](../VALIDATION.md)에 있습니다. 유형 명칭과 네이티브 값은 Microsoft의 [차트 유형 안내](https://support.microsoft.com/en-au/excel/available-chart-types-in-office)와 [XlChartType 열거형](https://learn.microsoft.com/en-us/office/vba/api/excel.xlcharttype)을 참고했습니다. XML 처리는 고정 버전 [xmldom 0.9.12](https://github.com/xmldom/xmldom)을 사용합니다.
