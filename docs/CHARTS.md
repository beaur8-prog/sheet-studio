# 차트 지원 — 0.4.0

**삽입 → 모든 차트**에서 유형을 선택합니다. 첫 행은 계열 이름, 첫 열은 범주이며 나머지 열은 값입니다. 차트 오른쪽 위 **설정**에서 제목·범례·데이터 레이블·축 제목을 바꾸고, 테두리의 8개 조절점으로 크기를 바꿉니다. 이동·크기 변경·설정 변경은 실행 취소할 수 있습니다.

## 새 차트 만들기

| 유형 | 구현한 변형 / 데이터 구성 |
|---|---|
| 세로 막대형 | 묶은형, 누적, 100% 누적 |
| 가로 막대형 | 묶은형, 누적, 100% 누적 |
| 꺾은선형 | 일반, 누적, 100% 누적 |
| 영역형 | 일반, 누적, 100% 누적 |
| 원형 | 첫 번째 값 계열 |
| 도넛형 | 여러 값 계열을 여러 고리로 표시 |
| 분산형 | 첫 열 X값, 나머지 열 Y값; 표식으로 표시 |
| 거품형 | 첫 열 X값, 이후 Y값·크기 열의 쌍 |
| 방사형 | 여러 계열 |
| 혼합형 | 막대 + 마지막 계열 꺾은선, 마지막 계열의 보조축 선택 |

10개 유형, 18개 기본 조합을 제공합니다. 여러 계열과 음수 값, 셀 수정 후 갱신을 지원합니다. XLSX에는 그림 대신 실제 DrawingML 차트를 기록하므로 Excel에서 계열과 유형을 편집할 수 있습니다. Windows XLSM 저장 경로는 설치된 Excel에서 차트를 생성·수정·삭제합니다.

## 기존 Excel 차트 가져오기

워크시트 안에 삽입된 차트의 계열 참조, 값 캐시, 제목, 범례, 기본 색상과 위치를 읽습니다. 지원하는 유형은 앱에서 미리 보고, 같은 통합 문서의 셀 값을 바꾸면 갱신합니다. 시트 이름 변경과 행·열 삽입/삭제 시 지원하는 A1 참조를 조정합니다. 단순 이름 정의도 셀 범위로 해석하며, 해석할 수 없는 수식은 원본에 저장된 차트 값으로 표시합니다.

가져온 차트는 원본 차트 XML, 직접 연결된 스타일·색·이미지 등의 패키지 파트와 관계를 보관합니다. XLSX로 다시 저장할 때 이 자료를 사용하며, 명시적으로 바꾼 제목·범례·레이블·축 제목과 데이터 참조/캐시를 반영합니다. 크기와 위치를 바꾸지 않으면 원래 앵커를 유지합니다. JSON 저장에도 원본 차트 자료가 포함됩니다.

가져온 차트의 **유형·배치·데이터 범위·보조축**을 변경하려면 **새 차트로 변환**을 선택해야 합니다. 변환하면 기존의 고급 서식을 제거하고 앱이 지원하는 차트를 만듭니다. XLSM에서 가져온 차트를 다른 시트로 복제한 경우에는 새 차트로 변환하거나 XLSX로 저장해야 합니다.

## 미리 보기와 호환성 한계

- 3D 막대·꺾은선·영역·원형은 2D로 미리 봅니다. 원본 XML의 3D 설정은 유지합니다.
- 주식형·표면형 및 ChartEx 기반 최신 차트는 원본 보존 안내 영역으로 표시합니다. 새로 만들거나 앱에서 실제 모양을 그리는 기능은 아직 없습니다.
- 추세선, 오차 막대, 상세 축 스케일, 다단계 범주, 개별 데이터 레이블 서식, 효과·테마·3D 조명 등을 동일하게 그리는 기능은 없습니다. 직접 수정하지 않은 원본 차트 XML에는 해당 설정이 남습니다.
- 차트 전용 시트, 외부/OLAP PivotChart와 통합 문서 외부 연결의 전체 종속 관계는 지원 범위가 아닙니다. 파일 전체를 그대로 보존하는 범용 OOXML 편집기는 아닙니다.
- 원형의 음수는 절댓값으로, 방사형의 음수는 0으로 미리 봅니다. 빈 값, 누적 음수, 복합 차트와 고급 서식의 모든 Excel 표시 규칙을 재현하지는 않습니다.
- 글꼴별 열 너비 환산은 근사치입니다. 원본과 앱의 차트 위치/크기가 약간 다를 수 있습니다.
- 새 범위는 최대 10,000개 데이터 행·32개 값 열입니다. 미리 보기는 계열당 1,000개 점과 가져온 그룹당 32개 계열로 제한합니다. 큰 원본 참조의 캐시는 잘라 덮어쓰지 않습니다.
- 가져오기는 통합 문서당 200개 차트, 차트당 원본 파트 합계 16 MB·연결 파트 250개 제한이 있습니다. 전체 입력/JSON은 100 MB, XLSM 원본/결과는 15 MB 제한입니다.

Windows와 macOS는 같은 차트 렌더링·XLSX 코드를 사용합니다. macOS 실제 패키징과 실행은 아직 검증하지 않았습니다. VBA 실행 및 VBA를 유지하는 XLSM 수정 저장은 Windows Excel 연결 전용입니다.

## 검증

- 단위 검사: 18개 조합의 XLSX·JSON 왕복, 여러 계열과 참조·값 갱신, 제목·범례·축 제목·레이블, 반복 저장, 이름 정의, 알 수 없는 차트와 연결 이미지 보존.
- 실제 Windows Electron: 10개 유형 삽입, 설정, 크기 조절, 저장/열기, 셀 변경, 명시적 변환, 실행 취소 및 재시작.
- 설치된 Windows Excel: 새 18개 조합을 열어 차트와 계열 값 확인 후 재저장. Excel이 만든 차트 13개(3D·표면형 포함)의 가져오기/재저장 검사.
- Windows Excel XLSM: 기존 차트 제목·크기·범례 수정, 18개 조합 생성, 삭제, 원본 파일 불변 검사. VBA 매크로 실행 성공 검사는 아닙니다.
- ChartEx는 합성 OOXML 자료의 파트·관계 보존을 검사했습니다. 로컬 Excel의 최신 차트 생성 호출이 거부되어 실제 최신 차트 파일 전체의 Excel 왕복은 검증하지 못했습니다.

정확한 실행 결과는 [검증 기록](../VALIDATION.md)에 있습니다. 유형 명칭과 네이티브 값은 Microsoft의 [차트 유형 안내](https://support.microsoft.com/en-au/excel/available-chart-types-in-office)와 [XlChartType 열거형](https://learn.microsoft.com/en-us/office/vba/api/excel.xlcharttype)을 참고했습니다. XML 처리는 고정 버전 [xmldom 0.9.12](https://github.com/xmldom/xmldom)을 사용합니다.
