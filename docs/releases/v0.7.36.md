# 0.7.36 · Windows 업데이트 도우미 시작 확인

[Office Studio PR #1](https://github.com/beaur8-prog/office-studio/pull/1)의 `e3cf073c86af1d8587e9e4a6049edc3d76e72d10`을 Sheet Studio의 독립 소스에 병합했다. 공통 `updater/`의 두 파일에 해당하는 이 앱의 파일은 `electron/studio-updater.cjs`, `electron/studio-update-windows.ps1`이다. Office Studio PR 자체를 병합하거나 Word·Slide 앱의 소스를 변경한 작업은 아니다.

## 수정

이전 Windows 업데이트는 Electron의 마지막 `quit` 이벤트에서 분리된 숨김 PowerShell을 시작했다. 앱이 종료돼도 PowerShell이 스크립트를 실행하지 못하면 설치 화면도 로그도 나타나지 않았다. 이제 앱이 실행 중일 때 숨김 cmd 콘솔을 통해 PowerShell 도우미를 시작하고, 추출한 스크립트의 SHA-256 및 도우미의 ID·부모 PID 응답을 확인한 뒤 기존 `app.quit()` 저장·종료 절차로 진입한다. 설치 파일은 앱과 해당 렌더러 프로세스가 모두 종료된 후 실행한다.

도우미가 실행되지 않거나 오류·시간 초과·잘못된 응답이 있으면 앱을 닫지 않는다. 다운로드한 검증된 설치 파일을 보여 주는 버튼, 로그 폴더와 직접 설치 안내를 제공한다. `last-install.log`와 `helper-startup.log`를 `%APPDATA%\Sheet Studio\updates`에 기록한다. 기존 문서 종료가 취소되거나 복구 저장이 실패하면 설치 요청을 지워 나중에 일반 종료해도 해당 업데이트를 실행하지 않는다.

Sheet Studio의 확인/다운로드/설치 분리, 도움말 업데이트 UI, 자동·수동 설정, 퍼센트·바이트·무결성 상태와 Windows 설치 화면 표시를 유지했다. 공통 파일을 통째로 덮어써 이 기능들을 제거하지 않았다. Mac의 수동 ZIP 교체와 Linux의 수동 다운로드도 유지한다.

## 빌드와 검증 범위

`Windows installer build and updater validation`은 GitHub의 별도 Windows 실행기에서 설치 파일을 만들고, 설치·재설치·삭제 및 파일 연결/다른 앱 등록 보존을 검증한다. 설치 파일과 체크섬은 Actions 산출물로 저장하며 공개 릴리스·리토스는 변경하지 않는다.

네이티브 도우미 검사는 별도 Electron 런타임과 버전이 있는 임시 테스트 설치 파일로 시작 응답→종료→설치→재실행, 종료 취소, 실행 차단, 스크립트 변조를 검사한다. 추가로 실제 완성 Sheet 편집기를 임시 폴더에 복사하여 테스트 업데이트를 수행하고, 기존 종료 IPC·복구 저장·입력/수식 복구와 복구 저장 실패 시 설치 취소를 검사한다. 테스트 파일과 프로필만 사용하며 사용자의 설치 앱과 문서는 변경하지 않는다. 설치 화면에서의 모든 사용자 선택이나 실제 Microsoft Excel/VBA 검사를 의미하지 않는다.
