# Sheet Studio v0.7.17 — 100만 셀·대용량 저장과 계산 개선

> **Windows 설치 안내: ‘실행 안 함’ 버튼만 보일 때**
> 설치 파일을 열었을 때 ‘Windows의 PC 보호’ 화면에 ‘실행 안 함’ 버튼만 보이면 **‘추가 정보’를 먼저 누르세요.** 그러면 **‘실행’ 버튼이 나타납니다.** ‘실행’을 누르면 설치가 시작됩니다.

Windows x64, Mac Apple Silicon, Ubuntu·Debian x64용입니다. 기존 리토스 공유 주소를 유지합니다.

## 변경 내용

- **문서 전체 100만 셀:** 모든 시트를 합쳐 기록된 셀 최대 1,000,000개를 지원합니다. 서식만 있는 셀도 포함하며, 한도 초과 작업은 전체를 취소합니다. 선택 편집·붙여넣기·자동 채우기는 한 번에 100,000셀까지입니다.
- **실행 취소 메모리 개선:** 문서 전체 사본 대신 바뀐 셀과 속성을 보관합니다. 최대 60단계·추정 128 MiB 예산을 적용하며 큰 작업으로 기록이 정리되면 알립니다.
- **자동 복구 저장 개선:** 셀을 묶음으로 나눠 변경된 부분을 저장합니다. 기존 복구 자료는 새 저장이 끝난 뒤 이전하며, 정상 종료·새로 고침 전에 저장을 기다립니다. 중요한 문서는 XLSX 또는 앱 문서로도 보관하세요.
- **대용량 처리 개선:** 파일 입출력, 일반 수식·조건부 서식 계산, 필터와 정렬을 작업 스레드로 옮겼습니다. XLSX 보조 처리의 전체 셀 DOM 생성을 없애고 서식을 재사용합니다.
- 기존 색 기준 필터, 모든 차트의 가로 선택값 누락 수정, 세로 막대형 항목명·색·간격, 숫자 연속 자동 채우기, 한글 조합 입력·셀 서식·Studio 표 교환 개선도 포함합니다.

100만 셀은 모든 PC에서 같은 속도를 보장하는 수치가 아닙니다. 첫 데이터 전달이나 큰 시트 교체에는 수초 지연이 남을 수 있습니다. 세 OS의 합성 문서 검사에서 XLSX 재열기는 약 19~48초였습니다. 긴 텍스트·개별 서식·많은 수식은 더 많은 메모리와 시간이 필요합니다. [기능별 한도와 사용법](https://github.com/beaur8-prog/sheet-studio/blob/v0.7.17/docs/CAPACITY.md)을 확인하세요.

## 설치와 실행

- **Windows x64:** `Sheet-Studio-0.7.17-Windows-x64-Setup.exe`에서 언어와 설치 경로를 선택합니다. 설치 후 시작 메뉴·바탕화면의 Sheet Studio로 실행하고 실행 중인 앱을 작업표시줄에 고정합니다.
- **Mac Apple Silicon:** `Sheet-Studio-0.7.17-macOS-arm64.dmg`를 열고 앱을 응용 프로그램 폴더에 복사해 실행합니다. ZIP도 제공합니다. Mac Intel용은 제공하지 않습니다.
- **Ubuntu·Debian x64:** `sudo apt install ./Sheet-Studio-0.7.17-Linux-amd64.deb`로 설치하고 앱 목록 또는 `sheet-studio` 명령으로 실행합니다. 한글이 네모로 표시되면 `sudo apt install fonts-noto-cjk`로 글꼴을 설치하고 앱을 다시 실행하세요. 앱 목록에서 실행한 아이콘에 Dash에 고정 / Pin to Dash를 사용하세요.

업데이트 전 문서를 `.sheet.json` 또는 `.xlsx`로 저장하고 이전 앱을 종료하세요. 기본 편집에는 Node.js나 Microsoft Excel이 필요하지 않습니다. VBA 연결에는 Windows 데스크톱 Excel이 필요하며 기존 15 MB 파일·200,000셀 변경 계획 제한을 유지합니다.

## 다운로드·실행 경고

Mac은 Apple Developer ID 미서명·미공증, Windows는 Authenticode 미서명입니다. 다운로드 시 브라우저에서 **위험한 파일·일반적으로 다운로드되지 않는 파일** 경고가 나타날 수 있습니다. **Windows의 PC 보호** 화면에서는 출처와 파일을 확인한 뒤 **추가 정보 → 실행**으로 설치할 수 있습니다. 추가 정보를 누른 뒤에도 실행 버튼이 없거나 조직 정책으로 차단되면 관리자에게 문의하세요. 악성코드 탐지 경고는 미서명·평판 경고와 구분해야 합니다.

## 검증 범위

[소스 회귀 검사](https://github.com/beaur8-prog/sheet-studio/actions/runs/39387553545)에서 Windows·Ubuntu 22.04·macOS 15의 단위 검사와 UI 23개 모음이 통과했습니다. 넓은 100만 셀·세로 100만 행의 CSV/XLSX 열기·저장·재열기, 편집·실행 취소·필터·정렬·프로세스 재시작 복구를 포함합니다. Windows 단위 검사 172개, Mac·Linux 각각 171개 통과 및 Windows 전용 1개 제외입니다.

배포 패키지 검증 결과와 SHA256SUMS.txt도 제공합니다. 실제 GNOME Dock 메뉴 클릭, Windows Excel/VBA 실행과 Microsoft Office 파일 왕복은 이번 검증에 포함하지 않았습니다. 한글 조합 검사는 Chromium 조합 경로를 사용하며 물리 키보드와 OS 입력기의 실기 시험은 아닙니다.

## 배포 검증 결과

[최종 배포 검사](https://github.com/beaur8-prog/sheet-studio/actions/runs/39411668351)에서 Mac arm64·Windows x64·Ubuntu 22.04 x64 모두 통과했습니다. 실제 배포 패키지의 100만 셀·100만 행 CSV/XLSX 왕복·편집·실행 취소·정렬·필터·재시작 복구와 기존 차트·셀 편집·서식·클립보드 회귀 검사를 통과했습니다. Windows 설치·재설치·제거·바로가기·앱 실행 및 사용자 자료 보존도 통과했습니다. Linux는 DEB로 설치한 앱으로 검사했습니다.

DMG·Mac ZIP·Windows Setup EXE·Linux DEB를 다시 내려받아 플랫폼별 manifest와 SHA-256을 대조했습니다. Mac 앱의 ad-hoc 서명 무결성과 실행 파일 10개의 소스 일치도 확인했습니다. 통합 SHA256SUMS.txt와 플랫폼별 manifest를 제공합니다.
