# Sheet Studio v0.7.20 — 편집 데이터 보호·파일 폴더·표 높이 개선

> **Windows 설치 안내: ‘실행 안 함’ 버튼만 보일 때**
> 설치 파일을 열었을 때 ‘Windows의 PC 보호’ 화면에 ‘실행 안 함’ 버튼만 보이면 **‘추가 정보’를 먼저 누르세요.** 그러면 **‘실행’ 버튼이 나타납니다.** 출처를 확인한 뒤 ‘실행’을 누르면 설치가 시작됩니다.

Windows x64, Mac Apple Silicon(arm64), Ubuntu·Debian x64용입니다. 기존 리토스 공유 주소를 유지합니다.

## 변경 내용

- **잘라내기 데이터 보호:** 잘라내기 후 다른 문서를 열거나 원본 셀·행 구조를 바꾸어도 현재 셀이 잘못 삭제되지 않습니다. 원본이 바뀌면 복사로 전환하며, 같은 문서의 시트 간 이동은 유지합니다.
- **저장 중 편집 보호:** 파일 처리 중 메뉴·단축키·붙여넣기로 문서 상태가 달라지지 않도록 막고, 작업 완료 후 정상 편집을 재개합니다.
- **파일 폴더 기억:** 열기·저장 창은 현재 파일 폴더를 우선 표시합니다. 새 문서는 마지막 사용 폴더를 사용하고 재시작·문서 전환 실행 취소 후에도 위치를 기억합니다. 취소·실패 시 위치는 유지합니다. 이전 Linux 포털에서도 시작 폴더를 지원하는 대화상자를 사용합니다.
- **표 행 높이 보존:** XLSX의 기본·개별·숨김 행 높이와 외부 표 붙여넣기의 높이를 보존합니다. 더 큰 대상 행은 줄이지 않으며 셀·병합·높이를 함께 실행 취소합니다.
- 문서 전체 100만 셀, 변경분 실행 취소, 자동 복구, 차트·색 필터·자동 채우기·한글 입력·Studio 표 교환 기능을 제공합니다.

## 검증과 범위

[사용 시나리오 검사](../USER-SCENARIO-QA.md)에서 Mac·Windows·Ubuntu의 편집·실행 취소/다시 실행·저장·재열기·재시작과 가로형·세로형 100만 셀 문서를 확인했습니다. 실제 배포 패키지의 세 OS 실행·Windows 설치·Linux DEB 검사를 통과한 파일을 공개합니다.

문서 전체 최대 1,000,000셀, 선택 편집·복사·붙여넣기·자동 채우기는 한 번에 100,000셀까지입니다. 큰 문서의 열기·저장에는 시간이 걸립니다. 실제 Microsoft Excel·Windows VBA 실행 및 Office 파일 왕복은 이번 검증에 포함하지 않았습니다.

Mac은 Apple Developer ID 서명·공증을 받지 않았고 Windows 설치 파일은 Authenticode 미서명입니다. 브라우저에서 위험하거나 일반적으로 다운로드되지 않는 파일이라는 경고가 뜨거나 OS에서 설치·실행 경고가 표시될 수 있습니다. 출처·체크섬과 조직의 보안 정책을 확인하세요.
