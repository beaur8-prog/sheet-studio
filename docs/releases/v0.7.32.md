# 0.7.32 · 앱 버전 표시 수정

개발 버전이며 GitHub 공개 릴리스·리토스 공유본은 갱신하지 않았다. 0.7.31의 변경을 포함한다.

## 원인과 수정

최신 소스가 0.7.31인 동안 Mac에 설치되어 실행 중인 앱은 0.7.30이었다. 이전 작업 시 화면이 잠겨 있어 로컬 앱 교체를 보류했던 상태다. 이 앱의 네이티브 정보 창에 표시된 0.7.30은 실제 설치 버전과 일치했다.

앱 내부의 정보 창은 빌드 시 package.json을 읽고, 개발 실행기는 dist/index.html 존재만 검사했다. 직접 패키징할 때도 dist를 그대로 복사했으므로 버전을 올린 뒤 화면을 다시 빌드하지 않으면 앱 메타데이터와 화면의 버전이 달라질 수 있었다.

- 데스크톱 화면은 허용된 IPC로 실행 중인 Electron 앱의 app.getVersion()을 읽는다. 브라우저 실행은 화면 빌드의 버전을 사용한다.
- 상단 앱 이름 옆, 창 제목, 도움말 → 앱 정보에 같은 버전을 표시한다.
- 화면 빌드에 app-version.json을 기록한다. npm start는 누락·버전 불일치 시 다시 빌드하고, 패키징은 누락·불일치 빌드를 거부한다. 이 검사는 버전 일치 검사이며 같은 버전 내 모든 소스 변경의 감지기는 아니다.
