# Sheet Studio v0.7.7

Linux x64 DEB 배포를 추가했습니다. Mac Apple Silicon과 Windows x64도 같은 버전으로 제공합니다.

### Linux (Ubuntu·Debian 계열 x64)

`Sheet-Studio-0.7.7-Linux-amd64.deb`를 다운로드한 폴더에서 설치합니다.

```sh
sudo apt install ./Sheet-Studio-0.7.7-Linux-amd64.deb
sheet-studio
```

설치 후 앱 목록의 **Sheet Studio**로도 실행할 수 있습니다. 앱은 일반 사용자로 실행하세요. 업데이트도 새 DEB 파일에 같은 설치 명령을 사용합니다. 삭제는 `sudo apt remove lattice-sheet-studio`입니다.

Ubuntu 22.04 x64 CI의 가상 화면에서 설치 및 앱 UI를 검증합니다. 다른 배포판·Wayland 데스크톱은 별도 검증하지 않았습니다. ARM64·RPM 패키지는 제공하지 않습니다. Linux에서 Windows Excel/VBA 연결은 지원하지 않습니다. 다운로드한 DEB는 서명된 패키지 저장소를 통한 배포가 아니므로 출처와 SHA-256 체크섬을 확인하세요.

Mac 앱은 Developer ID 서명·공증되지 않았고 Windows 설치 파일은 Authenticode 미서명입니다. 설치·첫 실행 시 OS 보안 경고 또는 실행 차단이 발생할 수 있습니다.

Windows: Setup.exe 설치 후 시작 메뉴에서 실행합니다. Mac: DMG에서 앱을 응용 프로그램 폴더로 복사합니다.

**Windows 다운로드·설치 경고 안내**

- 다운로드할 때 브라우저가 “위험한 파일”, “일반적으로 다운로드되지 않는 파일” 등의 경고를 표시할 수 있습니다. 경고 문구는 브라우저와 보안 설정에 따라 다릅니다. 이 페이지에서 받은 파일인지와 파일명·체크섬을 확인하세요. 경고가 없거나 미서명이라는 이유만으로 파일의 안전성이 보장되는 것은 아닙니다.
- 설치 파일을 실행할 때 **“Windows의 PC 보호”** 화면이 나타날 수 있습니다. 배포 출처를 확인하고 실행하기로 결정했다면 **추가 정보 → 실행**을 누르면 설치를 진행할 수 있습니다.
- **실행** 버튼이 없거나 회사·기관의 보안 정책으로 차단된 경우 관리자에게 문의하세요. 악성코드가 탐지되었다는 경고는 위의 미서명·평판 경고와 다르므로 실행하지 마세요.
