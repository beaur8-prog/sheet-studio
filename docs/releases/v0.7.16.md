# Sheet Studio v0.7.16 — 색 기준 필터·차트 선택값·세로 막대형 개선

> **Windows 설치 안내: ‘실행 안 함’ 버튼만 보일 때**
> 설치 파일을 열었을 때 ‘Windows의 PC 보호’ 화면에 ‘실행 안 함’ 버튼만 보이면 **‘추가 정보’를 먼저 누르세요.** 그러면 **‘실행’ 버튼이 나타납니다.** ‘실행’을 누르면 설치가 시작됩니다.

Mac Apple Silicon, Windows x64, Ubuntu·Debian x64용입니다. 0.7.14~0.7.16 개발 수정사항을 함께 배포하며 기존 리토스 공유 주소를 유지합니다.

## 변경 내용

- **색 기준 필터:** 열 머리글의 색 기준 필터에서 셀 채우기색·글자색·채우기 없음·자동 글자색을 선택한 뒤 확인으로 적용합니다. 지원되는 조건부 서식의 표시색과 색이 지정된 빈 셀도 포함합니다. 다른 열의 숫자·값 조건과 함께 사용하고 취소·실행 취소·다시 적용·자동 저장을 지원합니다. XLSX에 실제 색 필터와 차등 서식을 저장하며 기존 조건부 서식의 스타일 참조를 유지합니다.
- **차트 값 누락 수정:** 가로 한 줄의 숫자 네 개를 한 계열의 값 네 개로 읽습니다. 원형·도넛형의 한두 항목만 표시되던 경우를 수정했습니다. 데이터 계열의 행·열 방향 선택, 분산형 한 줄의 자동 X값, 거품형 X·Y·크기 자료 안내와 10종·18개 조합의 점 개수·XLSX 저장/재열기를 점검했습니다.
- **세로 막대형 정리:** 제목 행과 값 한 행은 자동으로 한 계열로 읽습니다. 항목명은 막대 바로 아래에 표시하고 한 계열은 같은 색을 쓰며 중복 범례를 생략합니다. 막대 폭·간격과 항목명 가운데 정렬, 긴 이름의 두 줄·말줄임·전체 이름 툴팁을 제공합니다. 여러 계열의 색·범례와 명시적인 행·열 방향은 유지합니다. 기존 차트에 열 방향이 저장되어 있으면 설정에서 자동을 선택해 새 해석을 적용할 수 있습니다.
- 기존 숫자 자동 채우기·범례 정렬·셀 이동 직후 한글 조합, 셀 서식·테두리·Studio 표 교환·Windows 설치 마법사·Ubuntu 아이콘 수정도 포함합니다.

## 설치와 실행

- **Windows x64:** `Sheet-Studio-0.7.16-Windows-x64-Setup.exe`에서 언어와 설치 경로를 선택합니다. 설치 후 시작 메뉴·바탕화면의 Sheet Studio로 실행하고 실행 중인 앱을 작업표시줄에 고정합니다.
- **Mac Apple Silicon:** `Sheet-Studio-0.7.16-macOS-arm64.dmg`를 열고 앱을 응용 프로그램 폴더에 복사해 실행합니다. ZIP도 제공합니다. Mac Intel용은 제공하지 않습니다.
- **Ubuntu·Debian x64:** `sudo apt install ./Sheet-Studio-0.7.16-Linux-amd64.deb`로 설치하고 앱 목록 또는 `sheet-studio` 명령으로 실행합니다. 한글이 네모로 표시되는 환경에서는 `sudo apt install fonts-noto-cjk`로 글꼴을 설치하고 앱을 다시 실행하세요. 앱 목록에서 실행한 아이콘에 Dash에 고정 / Pin to Dash를 사용하세요.

업데이트 전 문서를 `.sheet.json` 또는 `.xlsx`로 저장하고 이전 앱을 종료하세요. 기본 편집에는 Node.js나 Microsoft Excel이 필요하지 않습니다. VBA 연결에는 Windows 데스크톱 Excel이 필요합니다.

## 다운로드·실행 경고

Mac은 Apple Developer ID 미서명·미공증, Windows는 Authenticode 미서명입니다. 다운로드 시 브라우저에서 **위험한 파일·일반적으로 다운로드되지 않는 파일** 경고가 나타날 수 있습니다. **Windows의 PC 보호** 화면에서는 출처와 파일을 확인한 뒤 **추가 정보 → 실행**으로 설치할 수 있습니다. 추가 정보를 누른 뒤에도 실행 버튼이 없거나 조직 정책으로 차단되면 관리자에게 문의하세요. 악성코드 탐지 경고는 미서명·평판 경고와 구분해야 합니다.

## 배포 검증 결과

[최종 배포 검사](https://github.com/beaur8-prog/sheet-studio/actions/runs/39345234665)에서 Mac arm64·Windows x64·Ubuntu 22.04 x64 모두 통과했습니다. 실제 배포 패키지의 차트 10종·18개 조합·막대형 배치·색 기준 필터·숫자 자동 채우기·범례·한글 조합·테두리·입력 이동·수식·시트·셀 서식·클립보드·parity 감사 UI를 확인했습니다. Windows 설치·재설치·제거·바로가기·앱 실행과 사용자 자료 보존도 통과했습니다. Linux는 DEB를 설치한 앱으로 검사했습니다. 단위 검사는 Windows 158개, Mac·Linux 각각 157개 통과 및 Windows 전용 1개 제외입니다.

설치 파일 4개(DMG·Mac ZIP·Windows Setup EXE·Linux DEB)를 다시 내려받아 플랫폼별 manifest와 SHA-256을 대조했습니다. Mac 앱의 서명 무결성과 실행 코드 10개의 소스 일치도 확인했습니다. 통합 SHA256SUMS.txt와 플랫폼별 manifest를 제공합니다.
