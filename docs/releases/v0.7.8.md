# Sheet Studio v0.7.8 — Mac · Windows · Linux

Excel parity 감사에서 확인한 수식·참조, 범위 편집, 파일 저장과 화면 동작 문제를 수정했습니다.

## 다운로드

- Mac Apple Silicon: `Sheet-Studio-0.7.8-macOS-arm64.dmg` (ZIP도 제공)
- Windows x64: `Sheet-Studio-0.7.8-Windows-x64-Setup.exe`
- Ubuntu·Debian 계열 x64: `Sheet-Studio-0.7.8-Linux-amd64.deb`

## 주요 수정

- 빈 셀·빈 문자열을 구분하고 COUNTIF/SUMIF, 조회 함수, 생략 인자, 오류 집계와 1900년 날짜 계산을 수정했습니다.
- 동적 범위 끝점, 교집합·합집합 참조와 잘못된 참조 오류를 처리합니다.
- 여러 행·열 삽입·삭제, 시트 복제의 자기 참조, 조건부 서식 기준점과 교차 시트 참조를 수정했습니다.
- 숨김 셀 보호, 잘라내기 참조·병합 이동, 전치 수식, 다중 셀 채우기와 역방향 붙여넣기를 수정했습니다.
- CSV 반복 왕복, XLSX 날짜·숨김 행·조건부 서식, 피벗 원본 소실 시 저장 문제를 수정했습니다.
- 틀 고정 시 편집기·차트 겹침, 편집 중 시트 상태 저장, 자동 합계 실행 취소와 크기 표시를 개선했습니다.

병합 셀 일부 붙여넣기·병합 범위 정렬·숨김 셀을 가로지르는 잘라내기는 손상을 막기 위해 차단합니다. 원본이 없는 피벗은 XLSX 사본에서 마지막 결과를 일반 셀로 보존합니다. 앱 문서의 피벗 설정은 유지합니다.

## 설치·실행

Mac: DMG에서 앱을 응용 프로그램 폴더로 복사합니다. Mac 앱은 Apple Developer ID 서명·공증되지 않아 보안 경고나 실행 차단이 발생할 수 있습니다.

Windows: Setup EXE로 설치한 뒤 시작 메뉴에서 Sheet Studio를 실행합니다. 작업표시줄에는 설치된 앱을 고정하세요. 설치 파일은 Authenticode 미서명이며 다운로드 시 ‘위험한 파일’ 또는 ‘일반적으로 다운로드되지 않는 파일’ 경고가 표시될 수 있습니다. 출처를 확인하고 실행하기로 결정했다면 ‘Windows의 PC 보호’ 화면에서 **추가 정보 → 실행**으로 설치를 진행할 수 있습니다. 실행 버튼이 없거나 조직 정책으로 차단되면 관리자에게 문의하세요. 악성코드 탐지 경고는 미서명·평판 경고와 다르므로 실행하지 마세요.

Linux: 다운로드 폴더에서 다음을 실행합니다.

```sh
sudo apt install ./Sheet-Studio-0.7.8-Linux-amd64.deb
sheet-studio
```

일반 사용자로 실행하며 앱 목록에서도 열 수 있습니다. Ubuntu 22.04 x64를 검증 대상으로 합니다. ARM64·RPM 패키지는 제공하지 않습니다.

## 검증 범위

Mac에서 단위 테스트 109개 통과, Windows 전용 1개 건너뜀. 기본 실행, 시트 수명주기, 색상, 워크시트, 필터, 수식, 크기 조절, 셀 편집 및 감사 UI 검사를 통과했습니다. 플랫폼별 배포 빌드는 단위 검사와 기본 실행·시트 수명주기·색상·감사 UI 검사를 수행하며 Windows는 설치·바로가기, Linux는 DEB 설치 후 실행을 확인합니다.

실제 Windows Excel/VBA 및 Microsoft Excel 파일 왕복은 이번 검증에서 실행하지 않았습니다. 완전한 Excel 호환성을 보장하지 않습니다.
