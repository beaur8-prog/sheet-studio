# Sheet Studio 0.7.49 · Android 시스템 인쇄 / PDF

개발 수정이며 공개 배포가 아니다. 리토스·공개 설치 파일과 공유 링크는 변경하지 않는다.

## 사용자 동작

- Android 더보기 → **인쇄 / PDF**, 태블릿 파일 메뉴 또는 외부 키보드 **Ctrl+P**로 인쇄를 연다. 읽기 전용과 전체화면 뷰어에서도 출력할 수 있다.
- 현재 시트·선택 영역·차트만 중에서 고르고 세로/가로, 눈금선, 저장된 인쇄 영역, 차트/이미지 포함 및 개체별 페이지를 선택한다. 이후 Android 창에서 프린터 또는 **PDF로 저장**을 선택한다.
- 저장된 용지·여백·페이지 나눔·반복 제목·머리글/바닥글과 현재 수식 값을 기존 인쇄 엔진으로 준비한다. 시스템 용지·여백이 바뀌면 준비한 페이지 전체를 새 인쇄 가능 영역에 맞춘다. 시트의 페이지 나눔을 바꾸려면 앱 인쇄 설정에서 방향을 선택한다.
- 출력은 문서 사본이다. 출력 취소·실패는 원본과 편집 이력을 바꾸지 않는다. 편집 중 인쇄를 누르면 현재 입력을 먼저 확정하며 유효성 검사에 실패하면 입력 상태를 유지한다.
- 셀 20,000개/페이지 500개인 기존 인쇄 한도와 Android HTML 32 MiB 한도를 적용한다. 큰 문서는 선택 영역 또는 차트만 출력할 수 있다. 좁은 숫자 열도 전체 앞자리를 잃지 않도록 일반 형식 축약/지수, 지정 형식 ##### 표시를 적용한다.

## 구현과 범위

Android에서 막혀 있던 print 명령을 출력 권한으로 허용하고 기존 시트 인쇄 문서를 연결했다. 출력 문서를 준비한 뒤 별도 네이티브 WebView에서 시스템 PrintManager를 호출한다. 앱 화면 전체를 인쇄하지 않는다. 이전 설치본에 새 printDocument 연결이 없으면 업데이트 안내를 표시한다.

네이티브 인쇄에는 청크 전송과 별도 파일 작업 식별자를 사용한다. 용지 변경마다 격리된 WebView 인쇄 어댑터를 만들고 문서 로딩 후 프레임워크 콜백·취소 신호를 전달한다. JavaScript·네트워크·파일/콘텐츠 URI 접근과 네이티브 브리지가 없는 출력 전용 뷰이며, 종료·실패·취소 때 뷰/작업 잠금/임시 파일을 정리한다. Word/Slide의 기존 인쇄와 Windows/macOS/Linux의 기존 시트 인쇄 경로는 유지한다.

설계 근거: Android의 [HTML 인쇄](https://developer.android.com/training/printing/html-docs), [PrintDocumentAdapter 수명주기](https://developer.android.com/reference/android/print/PrintDocumentAdapter). 물리 프린터는 설치된 Android 인쇄 서비스가 필요하며, 실제 하드웨어 출력은 시험 장치 연결 후 별도 검증해야 한다.
