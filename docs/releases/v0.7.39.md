# 0.7.39 — 개발 중 · 미배포

0.7.38 이후 Excel 동작 비교 계획의 두 번째 4시간 개선 묶음입니다. 이 문서는 설치 파일의 공개 배포를 뜻하지 않습니다. [작업·검증 기록](../EXCEL-NEXT-FOUR-HOUR-20261105.md)과 [전체 계획](../EXCEL-BEHAVIOR-IMPROVEMENT-PLAN.md)을 확인하세요.

- 데이터 유효성 검사 작성·부분 범위 편집·목록·입력 안내·중지/경고/정보와 읽기 전용 현재 값 검사를 추가했습니다. 붙여넣기/채우기의 기존 입력 경고 우회 정책은 유지합니다. 규칙 자체의 복사/채우기 상속은 미완료입니다.
- 날짜·시간 서식 또는 해당 입력 규칙이 있는 셀에서 명확한 ISO 날짜·24시간제 시각을 숫자로 입력합니다. 일반/텍스트 식별자는 유지하며 1900/1904 날짜 체계를 구분합니다.
- 2색·3색 색조와 기본 그라데이션 데이터 막대를 작성·표시·인쇄·저장합니다. 고급 데이터 막대의 기본 규칙과 연결된 x14 정의가 저장 시 갈라져 유실되던 문제, 스필 결과의 조건부 서식 누락을 수정했습니다.
- 표 원본과 피벗을 안정적인 표/열 ID로 연결하고 증가한 자료·바뀐 이름을 새로 고침에 반영합니다. 사용한 열이나 표를 삭제하면 마지막 결과를 보존하고 연결 수정을 안내합니다.
- 파일 해석을 별도 작업 스레드로 분리해 단계 표시와 취소를 제공합니다. 실패/취소 때 현재 문서·복구·저장 위치를 보존합니다. 숨긴 시트가 활성인 파일은 보이는 시트로 엽니다. 최종 화면 적용 구간의 약 1초 지연은 남아 있습니다.
- 차트 계열별 이름·범위·색·순서, 분산형 X/Y·점 연결, 거품 크기, 혼합형 보조축을 지정합니다. 원본 차트는 기본 보존하며 고급 서식을 제거하는 명시적 변환 뒤 편집합니다. 같은 유형의 여러 XML 그룹을 혼합 차트로 오인하던 문제와 개별 연결선 해석을 수정했습니다.

실제 앱·단위·파일 구조·독립 엔진 검사를 Microsoft Excel/VBA 실행과 구분합니다. 새 실제 Excel/VBA·물리 IME·화면 읽기 프로그램 비교는 대기이며 전체 Excel 기능과 동일한 동작을 보장하지 않습니다. 공개 Windows·Mac 버전은 [사용자 가이드](../USER-GUIDE.md)를 따릅니다.
