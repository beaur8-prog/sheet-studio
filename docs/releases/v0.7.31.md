# Sheet Studio 0.7.31 — 개발·미배포

이번 개발 작업으로 공개 다운로드와 리토스 공유본을 갱신하지 않습니다. GitHub의 현재 공개 버전은 0.7.29입니다. 이 문서는 Git과 로컬 개발 앱에 적용하는 후속 개선입니다.

- **동적 배열:** FILTER·SORT·UNIQUE·SEQUENCE, 자동 확장/축소, `A1#`·`@`, XLOOKUP·INDEX의 행/열 반환. 시작 셀 편집·삭제, 부분 편집 보호, 복사·실행 취소와 XLSX 동적 배열 정보의 왕복을 연결했습니다.
- **빠른 입력과 저장:** 배열 계산 응답 전에 결과 셀을 덮어쓰던 문제를 수정했습니다. 배열 밖의 정상 숫자·한글 입력, 즉시 저장과 시트 이동, 정상 종료 후 복구를 함께 보존합니다.
- **배열 검색:** ISNUMBER·ISERROR·ISLOGICAL 등과 NOT을 셀별로 처리해 텍스트 검색·자료형 선택·오류 제외 FILTER 조합을 지원합니다.
- **대용량:** 원본 수식과 파생 결과를 분리합니다. 원본 한 셀로 100만 결과를 만들고 전체 삭제·복구·저장·재열기를 확인했습니다. 가져온 계산 가능 배열의 불필요한 캐시 레코드를 정리하며 스타일·메모는 유지합니다.
- **파일 보존:** 외부 통합 문서 연결의 번호·정의·원본 파트·경로와 캐시 자료형을 유지합니다. 연결 파일을 열거나 갱신하지 않습니다. 유효한 미지원 저장값의 근거를 표시하며, 값·시트 구조 변경 시 무효화하고 실행 취소로 복구합니다. 실제 이름 오류는 옛 숫자로 덮어쓰지 않습니다.
- **자료형:** 빈 텍스트와 실제 빈 셀, 빈 문자열 수식 캐시를 구분해 XLSX 저장·재열기 후 배열 값과 `ISBLANK`·`ISTEXT`가 달라지는 문제를 수정했습니다.
- **피벗:** 화면 밖 원본 때문에 필드가 사라지는 오류를 수정했습니다. 원본·미리 보기·새로 고침을 작업 스레드에서 계산하고 배열의 머리글·결과 셀과 실제 오류/텍스트를 구분합니다.
- **차트 설정:** 가져온 차트의 원본 데이터 참조를 표시합니다. 여러 시트·이름·불연속 범위를 내부 기본 범위로 잘못 안내하지 않습니다.
- **인쇄/PDF:** 페이지 설정 창, 첫/짝수 페이지를 포함한 머리글·바닥글과 페이지 필드를 추가했습니다. 차트·이미지는 시트 위치 또는 개체별 페이지로 출력합니다. 인쇄 영역 밖을 제외하고 페이지 경계를 나눠 표시하며, 페이지 맞춤에서 표·개체를 함께 축소합니다.

배열 파생 결과는 문서 합계 100만 개, 활성 배열 정의는 시트당 1만 개이며 XLSX의 원본+파생 셀 기록은 합계 100만 개입니다. 모든 최신 배열 함수·범용 LAMBDA·외부 연결 재계산·모든 Excel 도형/인쇄 효과를 구현한 것은 아닙니다. XLSM의 배열 편집과 문서 페이지 설정 저장은 Excel 또는 XLSX 사본을 사용하세요.

실제 Microsoft Excel/Windows VBA의 새 실행 검사는 수행하지 않았습니다. 공식 규칙·OOXML 파일 검사·기존 Excel 측정 자료·독립 LibreOffice 비교와 앱 검사를 구분합니다. [추가 계획·재현·측정](../CORE-FIVE-HOUR-20261031.md), [전체 검증 기록](../../VALIDATION.md), [수식](../FUNCTIONS.md), [인쇄](../PRINTING.md), [용량 한도](../CAPACITY.md)를 확인하세요.
