# Sheet Studio 0.7.45 · Android 전체화면 입력과 태블릿 편집

Android 전용 개발 수정이다. 공개 APK·GitHub 릴리스·리토스는 갱신하지 않았다. Windows/macOS/Linux의 화면·파일 대화상자·데스크톱 처리 경로는 유지한다.

## 변경

- 전체화면 뷰어와 문서 읽기 전용 권한을 분리한다. 일반 문서는 전체화면에서도 숫자·문자·한글·수식을 입력하고 Enter로 다음 셀에 이어 입력할 수 있다. 입력하지 않을 때 격자는 화면 전체를 사용하고 터치 입력 중에는 기존 입력줄을 표시한다.
- Esc는 전체화면만 종료한다. 입력 초안·선택·확정 값·dirty·실행 취소 이력을 유지하며 종료 확인창을 띄우거나 앱 종료를 요청하지 않는다. 패널이 열려 있으면 Esc가 패널부터 닫는다. 한글 조합 중에는 화면 전환을 유보한다.
- 더보기 → 읽기 전용으로 전환은 별도 권한이다. XLSM·잠긴 셀·피벗·배열 보호와 읽기 전용 원본 공유를 유지한다. 읽기 전용 문서에서도 Esc로 화면을 복원할 수 있으며 쓰기 권한은 주지 않는다.
- 넓은 Android 태블릿·DeX는 셀 탭 선택, 첫 타이핑·방향키 확정 이동, F2/두 번 탭 편집, 수식 입력 중 터치한 셀 참조 삽입, 우클릭 셀 메뉴, 행/열 크기 조절, 차트 이동·크기 조절, 숫자 연속 채우기·붙여넣기, 실행 취소/다시 실행과 자동 합계에 기존 데스크톱 명령을 사용한다. 작은 창은 기존 터치 흐름을 유지한다.

## Esc와 네이티브 호스트

[Sheet 전용 호스트 수정](https://github.com/beaur8-prog/office-studio/tree/codex/android-sheet-input-20261108)은 최신 통합 호스트 `7c3f7f8`을 기준으로 Sheet만 수정한다. 이전 호스트는 공통 브리지가 없거나 Back 처리에 실패해 false/null을 반환하면 Activity를 종료하는 경로가 있었다. Sheet의 하드웨어 Esc를 WebView의 입력기 전 처리와 Activity 양쪽에서 소비하고 전용 DOM 이벤트로 전달한다. Back도 직접 전달해 이 자동 종료 fallback을 제거한다. 스마트폰에서는 키보드 연결 정보만으로 입력 대기/IME를 켜지 않는다. 일반 편집의 명시적 종료 확인·복구 저장·닫기 API는 유지한다. 사용자 기기에서 Esc가 어떤 Android 키 이벤트로 전달됐는지까지 원격으로 확인한 것은 아니다.

시험 APK는 **1.0.4-qa/versionCode 5**, 별도 ID `io.officestudio.sheet.qa`다. 정식 앱 업데이트가 아니며 Word/Slide APK를 만들거나 배포하지 않는다.

## 검사

- 전체 단위 537개 중 536개 통과, Windows 전용 1개는 macOS에서 제외. 실패 0개.
- 전체화면/태블릿 UI 7개 시나리오군과 기존 Android UI 15개 시나리오군 통과. 숫자·한글·Enter·초안 유지, 읽기 전용 분리, 일반 키/전용 Esc 이벤트/Back, 수식의 터치 셀 참조·우클릭·크기 조절·차트 이동·복사·붙여넣기·연속 채우기·자동 합계·실행 취소/다시 실행·설정 유지·분할 창을 검사했다.
- 기존 Electron 실행/버전 0.7.45와 데스크톱 편집 회귀 검사 통과. OS 클립보드를 바꾸지 않는 시험 클립보드와 별도 프로필을 사용했다.
- 네이티브 호스트와 계측 Java 컴파일 통과. 실제 Android 에뮬레이터 결과는 완료 후 추가한다.

 실제 제조사 태블릿·DeX·물리 한글 키보드는 별도 검증 대상이며 브라우저 입력장치 모의를 실기기 검증으로 표시하지 않는다.
