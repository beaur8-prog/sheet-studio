# 0.7.37 · Windows 기존 설치 위치와 단일 재실행

Word Studio의 `da46ee7`, `522959c`, `9f4d402`, `0df66b5`, `39be35e` 변경을 확인하고 Sheet에 해당하는 설치·업데이트 경로만 반영했다. Word 작업본은 변경하지 않았다.

## 원인과 수정

- 기존 도우미는 `/currentuser`만 전달했다. 실행 중인 앱의 제거 등록을 HKCU/HKLM·32/64비트 보기에서 확인하여 해당 설치 범위와 폴더를 식별하고, 확인한 범위와 마지막 `/D=폴더` 인자를 Setup에 전달한다. 일반 제거 등록에 `InstallLocation`이 없는 실제 NSIS 형식은 인용된 `UninstallString`으로 확인한다. 등록이 없거나 설치 범위가 모호하면 시작 응답 전에 중단하여 앱을 유지한다.
- 이전 도우미가 전체 사용자 설치에 `/currentuser`만 전달해도 새 Setup은 명시적 `/D`가 없으면 기존 전체 사용자 설치를 보수한다. 새 도우미의 명시적 대상 폴더는 유지한다.
- 새 설치는 완료 화면에서 앱 실행을 선택할 수 있다. 기존 설치를 갱신할 때는 완료 화면의 실행 항목을 숨겨 도우미가 설치 종료·버전 확인 후 한 번만 실행한다. Sheet의 단일 인스턴스 보호도 유지한다.
- 강제 언어 선택창을 없애 Windows UI 언어로 한국어/영어를 자동 선택한다. 설치 진행 화면은 그대로 표시한다.
- Windows PowerShell 5.1에서 설치 프로세스의 네이티브 핸들을 유지하고 종료 후 갱신하여 성공 코드를 읽는다. 설치 취소·실패·버전 불일치 시 로그와 수동 설치 안내를 표시한다.

기존 업데이트 메뉴·수동 옵션·진행률, 문서 복구 저장·종료 취소, Mac 파일 선택창·빈 문서 시작은 유지했다. 공개 릴리스·리토스·다운로드 링크는 변경하지 않는다.

## 검증 계획과 제한

Windows CI에서 고정된 이전 소스 `0aba391`의 0.7.36 Setup과 새 Setup을 각각 빌드한다. 실제 NSIS 설치와 Windows PowerShell 5.1 도우미를 사용하여 현재 사용자/전체 사용자 사용자 지정 폴더 갱신, 옛 도우미로 생긴 중복 설치의 보수, 앱 버전·단일 재실행·바로가기·사용자 문서/복구 보존을 확인한다. 기존 강제 언어 창은 이전 Setup으로 재현한다. 바로가기 대상은 한글 경로를 보존하는 IShellLinkW로 읽는다. Word 최신 CI의 WScript.Shell 경로 비교 실패를 제품 수정의 근거로 삼지 않았다.

네이티브 도우미 시험은 설치 인자·응답 확인 후 종료·종료 취소·시작 차단·변조·미등록 앱 유지, 실제 Sheet 시험은 정상 종료와 복구 저장 실패 시 취소 및 입력·수식 복구를 검사한다. 시험은 격리 CI 설치/프로필에서만 수행한다. 실제 Microsoft Excel/VBA 검사를 뜻하지 않는다. 최종 결과는 검증 후 이 문서와 VALIDATION에 기록한다.
