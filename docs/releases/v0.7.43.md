# 0.7.43 — Android 실제 창·종료·셀 입력 미리보기

날짜: 2026-11-08. 개발 버전이며 공개 배포는 별도 요청 시 진행한다.

## 발견한 원인과 수정

- 별도 Office Studio Android APK 프로젝트를 확인했다. 기존 Sheet APK 1.0.1은 Sheet `89053c6`을 포함하고 있어 이후 0.7.42 소스 수정은 설치 앱에 들어 있지 않았다. 또한 네이티브 부모가 카메라 cutout 높이를 padding으로 예약하고 창의 cutout 진입 모드도 Sheet에 적용하지 않았다. 단순히 웹 CSS 높이만 고쳐서는 이 영역을 쓸 수 없었다.
- APK 호스트는 Sheet에서만 창·WebView를 상하단 전체로 확장하고 시스템줄·cutout을 웹에 구분 전달하도록 수정했다. 카메라 사각형 좌우에 상단 메뉴를 배치할 수 있으면 별도 빈 행을 두지 않는다. IME와 안전한 조작 영역은 유지한다.
- 뒤로 가기에서 기본 모드를 바꾸거나 새 빈 문서를 여는 흐름을 앱 종료 확인으로 바꿨다. 패널·입력 중인 초안을 먼저 해결하고, `취소`는 문서를 유지한다. 확인의 `닫기`는 복구 저장을 완료한 뒤 네이티브 Activity를 종료한다. 종료 API를 Sheet에 노출하지 않았던 호스트도 수정했다. 저장 또는 종료 실패 시 문서를 유지하고 오류를 알린다.
- Android에서 숫자·문자·한글·수식을 입력하는 동안 현재 셀에 초안을 즉시 미리 표시한다. 문서·계산·실행 취소는 Enter/완료 때만 갱신하고 취소 시 원래 표시로 복원한다.

## 로컬 검사

- 전체 단위 검사 535개 중 534개 통과, 실패 0개, Windows 전용 1개는 macOS에서 제외.
- Android Chrome UI 모의 검사 15개 시나리오군 통과. 카메라 옆 메뉴·입력 포커스·연속 Enter·한글·미리보기의 모델 불변·HTML 이스케이프·취소 복원·닫기 취소/실패/재시도·대용량 열기를 확인했다.
- Sheet 프로덕션 빌드와 별도 APK 호스트의 Sheet debug Java 및 Android 계측 검사 Java 컴파일 통과.
- 실제 Electron 실행 검사 결과와 Android 에뮬레이터 검사 결과는 최종 실행 후 기록한다.

## 패키지와 범위

[Office Studio Android 수정 브랜치](https://github.com/beaur8-prog/office-studio/tree/codex/android-sheet-lifecycle-20261108)에서 Sheet만 수정한다. 로컬/CI 네이티브 검사는 `io.officestudio.sheet.qa`라는 별도 시험 패키지로 수행한다. 정식 설치 앱·서명 키·사용자 문서·OS 클립보드는 사용하지 않는다. 기존 Word/Slide 작업본은 수정하지 않는다. 공개 APK·GitHub 릴리스·리토스 페이지는 변경하지 않는다.
