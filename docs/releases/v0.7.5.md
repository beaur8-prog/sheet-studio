# Sheet Studio v0.7.5

Windows 작업표시줄 고정을 위한 설치형 릴리즈입니다.

- 임시 폴더에서 실행되는 포터블 대신 사용자별 고정 경로에 설치합니다.
- 시작 메뉴·바탕화면 바로가기와 실행 앱의 AppUserModelID를 일치시킵니다.
- Mac은 Apple Silicon용만 제공합니다.

## Windows 설치와 고정

1. Sheet-Studio-0.7.5-Windows-x64-Setup.exe를 다운로드하고 실행합니다.
2. 이전 버전의 작업표시줄 아이콘은 고정 해제하고 이전 앱을 종료합니다.
3. 시작 메뉴의 Sheet Studio를 실행합니다.
4. 실행 중인 아이콘을 우클릭하고 ‘작업 표시줄에 고정’을 선택합니다.
5. 앱을 종료한 후 고정 아이콘으로 다시 실행합니다.

Setup 파일 자체를 고정하지 마세요. 업데이트 전에 작업 문서를 파일로 저장하세요.

Windows CI에서 패키지 빌드와 앱 실행을 확인합니다. 실제 PC에서 작업표시줄 고정·재실행은 별도 확인이 필요합니다. Windows VBA와 실제 Excel 호환성은 검증하지 않았습니다.
