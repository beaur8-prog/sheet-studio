# Sheet Studio v0.7.11 — 설치 마법사·Ubuntu 아이콘·셀 입력·테두리·차트 수정

Windows를 Word Studio와 같은 설치 마법사 방식으로 배포합니다. Mac Apple Silicon과 Linux x64도 함께 제공합니다. 기존 리토스 공유 주소는 유지합니다.

## 다운로드와 설치

- **Mac Apple Silicon:** `Sheet-Studio-0.7.11-macOS-arm64.dmg`를 열어 앱을 응용 프로그램으로 복사하고 실행합니다. ZIP도 제공합니다. Intel Mac용은 제공하지 않습니다.
- **Windows x64:** `Sheet-Studio-0.7.11-Windows-x64-Setup.exe`를 실행해 언어와 설치 경로를 선택합니다. 설치를 마치면 시작 메뉴나 바탕화면의 Sheet Studio로 실행합니다. 기본 경로는 `%LOCALAPPDATA%\Programs\Sheet Studio`이며 제거 후에도 사용자 문서·앱 데이터는 유지합니다. 작업표시줄에는 설치된 앱을 고정하세요.
- **Linux x64:** `sudo apt install ./Sheet-Studio-0.7.11-Linux-amd64.deb`로 설치한 뒤 앱 목록 또는 `sheet-studio` 명령으로 실행합니다. 업데이트 전 실행 중인 이전 앱을 종료하고 앱 목록에서 다시 실행한 뒤 **Dash에 고정**을 선택합니다.

기존 문서를 저장하고 이전 앱을 종료한 뒤 업데이트하세요. Node.js나 Microsoft Excel은 기본 편집에 필요하지 않습니다. Windows VBA 연결에는 데스크톱 Excel이 필요합니다.

## 변경 내용

- Windows 설치 마법사에 한국어·영어와 설치 경로 선택, 완료 후 실행을 제공합니다. 설치·재설치·제거 시 사용자 자료 보존을 검사합니다.
- Ubuntu의 아이콘 크기를 9개로 늘리고 desktop 파일·X11 WM_CLASS·Wayland app_id를 맞췄습니다. GNOME이 앱 아이콘과 실행 창을 연결하도록 수정했습니다.
- 셀에 바로 입력한 뒤 방향키를 누르면 입력을 확정하고 해당 방향으로 이동합니다. F2·더블클릭·수식 입력줄에서는 글자 커서를 이동하며, 수식 참조 선택과 한글 조합 처리는 유지합니다.
- 맞닿은 셀의 공유 테두리를 한 번만 그려 안쪽 선과 윤곽선의 굵기를 맞췄습니다. 셀 서식 미리보기, 병합·숨김·확대·틀 고정을 반영합니다.
- 차트가 첫 숫자 열·첫 숫자 행을 무조건 제외하던 문제를 수정했습니다. 제목·항목명은 자동 구분하고 차트 설정에서 첫 행·첫 열의 용도를 직접 지정할 수 있습니다. 숫자 한 열도 지원하며 XLSX 저장·재열기에 반영합니다.

## 보안 경고와 검증 범위

Mac은 Developer ID 미서명·미공증이고 Windows 설치 파일과 앱은 Authenticode 미서명입니다. 브라우저에서 **위험한 파일·일반적으로 다운로드되지 않는 파일** 경고가 나타날 수 있습니다. 설치 시 **Windows의 PC 보호**가 나오면 출처와 파일을 확인한 뒤 **추가 정보 → 실행**으로 진행할 수 있습니다. 실행 버튼이 없거나 조직 정책으로 차단되면 관리자에게 문의하세요. 악성코드 탐지 경고는 단순 미서명·평판 경고와 구분해야 합니다. 배포 방식을 맞췄다고 경고가 사라지는 것은 아닙니다.

Mac·Windows·Ubuntu에서 차트 회귀 검사를 통과했고 Ubuntu 22.04·24.04에서 아이콘·X11·중첩 Weston Wayland 식별자를 확인했습니다. 실제 GNOME Dock 메뉴 클릭, 실제 Windows Excel/VBA 및 Microsoft Office 파일 왕복은 이번 검증에 포함하지 않았습니다. 배포 패키지 검사 결과는 릴리즈 및 검증 기록에서 확인하세요.
