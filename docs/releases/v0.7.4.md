# Sheet Studio v0.7.4 — Mac · Windows

한국어 리본 UI로 표·수식·필터·차트·피벗테이블을 편집하는 로컬 스프레드시트 앱입니다. 이번 버전은 시트 삭제·이름 변경 시 참조와 더블클릭 동작을 수정했습니다.

## 다운로드

| 운영체제 | 파일 |
| --- | --- |
| Mac Apple Silicon (M 시리즈) | [DMG](https://github.com/beaur8-prog/sheet-studio/releases/download/v0.7.4/Sheet-Studio-0.7.4-macOS-arm64.dmg) · [ZIP](https://github.com/beaur8-prog/sheet-studio/releases/download/v0.7.4/Sheet-Studio-0.7.4-macOS-arm64.zip) |
| Mac Intel | [DMG](https://github.com/beaur8-prog/sheet-studio/releases/download/v0.7.4/Sheet-Studio-0.7.4-macOS-x64.dmg) · [ZIP](https://github.com/beaur8-prog/sheet-studio/releases/download/v0.7.4/Sheet-Studio-0.7.4-macOS-x64.zip) |

Node.js나 Excel 없이 일반 표 편집을 실행할 수 있습니다. `Source code`는 개발자용 소스이며 설치 앱이 아닙니다. 각 플랫폼의 `SHA256SUMS`와 매니페스트를 Assets에 함께 제공합니다.

## 설치와 실행

**Mac:** 이 Mac에 관하여에서 Apple 칩/Intel을 확인 → 맞는 DMG 다운로드 → `Sheet Studio.app`을 응용 프로그램 폴더로 복사 → 복사한 앱 실행. ZIP을 선택했다면 압축을 풀어 `.app` 전체를 복사하세요.

**Windows:** EXE 다운로드 → 원하는 폴더에 보관 → 더블클릭. 설치 마법사가 없는 포터블 앱이며, 필요하면 바탕화면 바로가기를 만드세요.

Mac은 ad-hoc 서명·미공증, Windows는 Authenticode 미서명 패키지입니다. OS가 실행을 경고하거나 차단할 수 있습니다. 다운로드 출처를 확인하고 운영체제 안내·조직 보안 정책에 따라 실행 여부를 결정하세요.

**업데이트:** 작업을 파일로 저장하고 앱 종료 → 새 앱으로 교체. 자동 저장만 믿지 말고 중요한 문서는 `.sheet.json` 또는 `.xlsx`로 백업하세요.

## 첫 사용

1. A1에 `품목`, B1에 `금액`, B2에 `3000`, B3에 `2500`을 입력합니다.
2. B4에 `=SUM(B2:B3)` 입력 → Enter → `5500`을 확인합니다.
3. **파일 → XLSX 저장** 또는 **앱 문서 저장 (.sheet.json)**으로 저장합니다.
4. **도움말 → 예제 통합 문서**에서 수식·서식 예제를 볼 수 있습니다.

[전체 사용자 가이드](https://github.com/beaur8-prog/sheet-studio/blob/v0.7.4/docs/USER-GUIDE.md)에는 화면 구성, 시트 편집, 함수, 정렬·필터, 차트, 피벗, 저장, 단축키, 문제 해결 방법이 있습니다. 리토스 유저 가이드의 구성을 참고해 작성했습니다.

## v0.7.4 수정 내역

- 삭제된 시트의 참조를 `#REF!`로 고정해 같은 이름의 새 시트에 잘못 재연결되지 않도록 수정.
- 시트 이름 변경 시 조건부 서식의 수식 참조도 갱신하도록 수정.
- 시트 탭 더블클릭으로 이름 변경 창이 열리지 않던 문제 수정.
- macOS 패키징의 Finder 메타데이터 정리와 출력 폴더 지정 지원.
- Mac arm64·Intel, Windows x64 릴리즈 빌드와 설치·사용 가이드 추가.

| 대상 | 빌드·단위 테스트 | 패키지 실행·시트 회귀 테스트 |
| --- | --- | --- |
| Mac Apple Silicon | 통과 | 통과 |

| Windows x64 | 통과 | 통과 |

다운로드 5개의 SHA-256은 GitHub에 저장된 파일의 digest와 일치하는 것을 확인했습니다.

macOS arm64 로컬 검증에서 단위 테스트 98개 통과·Windows 전용 1개 건너뜀, 설치된 앱의 시트 수명주기 회귀 테스트 및 서명 검증을 통과했습니다. 공개 패키지는 플랫폼별 빌드·기본 실행·시트 수명주기 검증을 통과한 파일만 첨부합니다.

**Windows VBA 실행과 실제 Microsoft Excel에서 XLSX/XLSM을 열고 다시 저장하는 호환성 검증은 수행하지 않았습니다.** VBA 연결은 Windows 데스크톱 Excel이 설치된 환경에서만 사용할 수 있으며, Mac Excel 연결은 지원하지 않습니다.

동적 배열, 전체 열 참조 `A:A`, Power Query, 공동 편집 등은 미지원입니다. Excel의 미지원 개체·서식은 저장 시 손실될 수 있으므로 중요한 원본은 사본으로 작업하세요. [파일 지원 범위](https://github.com/beaur8-prog/sheet-studio/blob/v0.7.4/IO-NOTES.md)
