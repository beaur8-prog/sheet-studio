# Sheet Studio v0.7.6

> **다운로드·설치 전 안내:** 현재 Mac 앱은 Apple Developer ID 서명·공증을 받지 않았고, Windows 설치 파일은 코드 서명(Authenticode)이 되어 있지 않습니다. 따라서 다운로드 후 설치하거나 처음 실행할 때 운영체제의 보안 경고가 표시되거나 실행이 차단될 수 있습니다. 경고 표시 여부는 OS 버전과 보안 설정에 따라 다릅니다. 다운로드 출처를 확인하고, 회사·기관 PC에서는 관리자 정책을 따르세요.

- 선택한 범위의 글꼴 색·채우기 색을 적용 버튼으로 확정합니다.
- 팔레트에 대상 범위, 색 미리보기, 적용·취소 버튼을 제공합니다.
- 셀 우클릭 메뉴에서 글꼴 색과 채우기 색을 선택할 수 있습니다.
- 창 포커스 이동 또는 포인터 취소 후 남은 드래그 상태를 해제합니다.
- 색상 적용은 한 번의 실행 취소로 되돌립니다.

Windows: Setup.exe로 설치 후 시작 메뉴의 Sheet Studio를 실행하세요. 기존 고정 아이콘은 해제하고 설치된 앱을 다시 고정하세요. Mac은 Apple Silicon DMG를 제공합니다.

선택 범위만 변경, 적용 전 미변경, 취소, 우클릭 메뉴, 실행 취소·다시 실행을 앱 UI 테스트로 검증합니다. 실제 Windows 작업표시줄 클릭과 Windows VBA·실제 Excel 왕복 호환성은 직접 검증하지 않았습니다.
