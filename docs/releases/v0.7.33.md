# 0.7.33 · 업데이트 메뉴와 진행 화면

개발 버전이며 별도의 배포 요청 전까지 GitHub 공개 릴리스와 리토스 공유본을 갱신하지 않는다. 0.7.32의 변경을 포함한다.

## 사용 방법

앱의 **도움말 리본**과 운영체제의 **도움말 메뉴**에서 **업데이트 확인 / 수동 업데이트 / 업데이트 진행 상황**을 연다.

- 현재 버전·새 버전·마지막 확인 시간을 표시한다. 수동 확인은 배포 정보만 조회하며, **새 버전 다운로드**를 눌러야 파일을 받는다.
- **자동으로 확인하고 다운로드 / 수동으로만 확인**을 선택하고 재실행 후에도 설정을 유지한다.
- 확인 → 다운로드(퍼센트·받은 용량/전체 용량) → SHA-256 무결성 확인 → 설치 준비를 표시한다. 업데이트 창을 닫아도 하단 상태 표시줄에서 진행을 보고 다시 열 수 있다.
- 네트워크·파일 검증 실패를 창에 표시하고 재확인을 지원한다. **설치 파일 직접 받기**는 해당 앱의 공개 릴리스 페이지를 연다.
- Windows는 **설치 화면 열기 → 종료하고 업데이트** 후 복구 저장·정상 종료를 기다리고 설치 화면과 진행률을 표시한다. 설치를 마치면 앱을 다시 실행한다. 종료가 취소되면 설치 작업도 취소한다.
- Mac은 다운로드한 ZIP과 수동 교체 안내를 제공한다. 문서를 저장하고 앱을 종료한 뒤 응용 프로그램 폴더의 앱을 직접 교체한다. Linux는 공개 설치 파일을 직접 받아 설치한다.

다운로드된 파일도 설치 직전에 서버의 배포 정보와 파일 크기·SHA-256을 다시 확인한다. 창을 닫는 것은 다운로드 취소가 아니다. 실제 파일을 고르거나 임의 주소·명령을 업데이트 IPC로 전달하는 기능은 제공하지 않는다.

## 검증

Mac arm64에서 단위 검사 416개 중 415개 통과·Windows 전용 1개 제외·실패 0개, 업데이트 엔진 검사 24개 통과를 확인했다. 소스 및 완성된 Mac 패키지에서 새 메뉴·자동/수동 설정·50/75/100% 진행률·용량·창 닫기/재열기·오류/재시도·설정 및 문서의 재실행 복구·IPC 입력 거부를 검증했다. 파일 IPC·기본 편집·실행 취소/다시 실행, 즉시 새로 고침·정상 종료 복구, ad-hoc 서명 무결성도 확인했다.

UI 검사에서는 격리 프로필과 메모리 응답·실행 불가능한 64바이트 테스트 파일을 사용한다. 실제 GitHub 설치 파일을 실행하거나 실제 사용자 문서·OS 클립보드를 테스트 데이터로 사용하지 않는다. Windows 설치 마법사의 실제 클릭 검증과 Microsoft Excel/VBA 실행 검사를 의미하지 않는다. 

재현: `npm run test:updates`, `node tests/ui-updates.mjs`, `node tests/ui-updates.mjs --packaged`. GitHub Actions의 `Worksheet editing regression`에서 `scope=updates`를 선택하면 Mac·Windows·Ubuntu에서 업데이트 로직·화면·복구 시나리오와 Windows helper 구문을 검사한다.

### 최종 결과

앱 동작은 `fa566a7`, CI 테스트 프로필의 첫 생성 경로 수정은 `5c689d5`다. [최종 CI 41199553416](https://github.com/beaur8-prog/sheet-studio/actions/runs/41199553416)의 **Windows·Mac·Ubuntu 세 작업이 모두 통과**했다. 각 OS에서 단위 검사와 업데이트 엔진 24개, 업데이트 UI·문서 복구를 실행했다. Windows는 단위 검사 416개 모두, Mac·Ubuntu는 415개 통과·Windows 전용 1개 제외다. Windows PowerShell helper 구문 검사도 통과했다. Linux UI는 지원 범위인 메뉴·직접 다운로드·자동 기능 비활성화·IPC와 복구를 검사하며 자동 설치를 지원한다는 의미가 아니다. 첫 CI는 테스트 폴더가 없는 새 환경에서 시작 전에 실패했으며, 이를 시스템 임시 폴더로 수정한 뒤 세 OS 전체를 재실행했다.

Mac 설치 앱과 전체 사용자 프로필을 백업하고 정상 종료 후 **0.7.33**으로 교체·실행했다. 기존 문서와 시트가 복구됐고, 실제 앱에서 도움말의 세 메뉴와 업데이트 창을 열었다. 실제 GitHub 서버 확인에서 “설치된 버전보다 새로운 공개 버전이 없습니다”와 마지막 확인 시간이 표시되는 것을 확인했다. 사용자의 자동 업데이트 설정은 유지했다.
