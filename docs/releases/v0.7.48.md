# Sheet Studio 0.7.48 · Android 평균 범위 자동 선택

개발 수정이며 공개 배포가 아니다. 리토스·공개 설치 파일·공유 링크는 바꾸지 않는다. 넓은 Android 태블릿·DeX 편집 화면의 평균 버튼을 보강하며 Windows/macOS/Linux의 기존 평균 입력 UI는 유지한다.

## 재현과 수정

- 태블릿의 수식 → 평균 버튼은 `=AVERAGE(`만 넣어 범위가 비어 있었다. 0.7.47에서 실제 빌드로 재현했다.
- Android 넓은 편집 화면에서도 합계와 같은 범위 탐색을 사용한다. 빈 결과 셀에서는 위쪽, 다음으로 왼쪽의 연속된 숫자 범위를 제안한다. 예: A1:A3이 숫자일 때 A4에서 평균 → `=AVERAGE(A1:A3)`.
- 행/열을 선택한 경우 선택 범위와 빈 결과 행/열을 인식한다. 수식의 참조 부분을 선택하고 시트에 테두리를 표시해 범위를 바로 교체할 수 있다. Enter 전까지 원본·이력을 바꾸지 않으며 Esc는 초안을 취소한다.
- 여러 열/행의 평균을 동시에 만들 때 공통 모서리는 원본 전체 범위를 직접 평균한다. 숫자 개수가 다른 열의 평균들을 다시 평균해 가중치가 달라지는 오류를 피한다.
- 실제 활성 편집기에 참조 선택을 적용한다. 파일을 연 직후에도 넓은 Android 화면의 편집 방식을 따라 인라인 편집기를 활성화한다. 기존 스마트폰의 합계·평균 범위 제안 대화상자와 원본·보호·입력·undo/redo 경로는 유지한다.
- 자동 합계의 기본 동작과 기존 선택 한도 100,000개 셀을 유지한다. 작업 스레드에 허용한 함수 이름 SUM/AVERAGE만 전달하고 검증한다.

## 검사

- 단위 검사 547개 중 546 통과, Windows 전용 1개 제외. 기존 합계 범위와 새 평균의 위/왼쪽·선택 범위·빈 위치·데이터 덮어쓰기 거부·불균등 숫자 개수의 전체 평균을 확인했다.
- `tests/android-average-range.mjs`: 태블릿 실제 리본 평균 버튼, 참조 선택/테두리, 범위 교체, Enter, Esc, 단일/다중 결과 undo/redo, 가로·세로·행렬 계산, 스마트폰 제안 대화상자와 Enter, 기존 SUM/데스크톱 평균 분리 통과.
- `tests/viewer-modes.mjs`: 기존 8개 Android/데스크톱 편집·뷰어·클립보드 모의·자동 합계 시나리오 그룹 통과.
- 재현 JSON·스크린샷·로그는 `test-results/android-average-range/0.7.48/`에 보관한다. 네이티브 APK 검사도 아래와 같이 완료했다.
