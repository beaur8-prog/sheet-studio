# Sheet Studio 0.7.47 · Android 숫자 폭과 크기 조절

개발 수정이며 공개 배포가 아니다. 리토스 공유 링크·공개 설치 파일은 변경하지 않는다. Windows/macOS의 숫자 표시와 드래그 방식은 유지한다.

## 재현과 원인

- Android 태블릿에서 폭 64px인 A열에 `123456789`를 숫자 형식으로 표시하면 `123,456,789`의 왼쪽 약 25px가 셀 밖으로 밀려 가려졌다. 오른쪽 정렬된 flex 자식의 폭 초과를 그대로 잘라 끝자리만 보이던 문제다.
- 10만 개 값이 있는 문서에서 포인터 이동 60개를 한 번에 전달하면 처리에 12,705.9ms가 걸렸다. 매 이동마다 전체 1,048,576개 행의 위치와 필터 상태를 다시 만들고 렌더링을 예약했다. 이 수치는 이벤트 처리 구간의 합계이며 실제 사용자의 드래그 시간이나 특정 Android 기기의 FPS를 뜻하지 않는다.

## 수정

- Android의 일반 숫자는 폭에 맞춰 소수 자릿수를 줄이고, 필요하면 부호·앞자리·지수가 모두 들어가는 지수 표기로 표시한다. 일반 형식의 12자리 이상 큰 수도 지수 표기를 쓴다. 통화·백분율·날짜·고정 숫자 등 지정 형식이 들어가지 않으면 `#####`로 표시한다. 숫자의 일부만 남겨 다른 값처럼 보이지 않게 한다.
- 열 너비·병합 범위·확대 배율·글꼴·크기·굵게/기울임과 필터 버튼 공간을 반영한다. 캔버스 측정 캐시는 글꼴/문자열별 최대 4,096개로 제한하며 셀 DOM의 폭을 매번 읽지 않는다. 텍스트·숫자 모양 문자열·텍스트 형식·수식 오류·입력 중 초안은 별도로 유지한다.
- 이 처리는 화면 문자열만 바꾼다. 원본 값·수식·계산·복사·저장은 바뀌지 않는다. 수식 입력줄과 접근성 이름에는 전체 값이 남고, 생략된 셀의 툴팁에는 전체 표시값과 열 확대/자동 맞춤 안내를 제공한다.
- Android의 마우스 행/열 조절은 드래그 중 안내선과 픽셀 크기만 프레임별로 갱신하고 놓을 때 한 번 확정한다. 안내선은 시작 경계에서 이동량을 계산하므로 고정 창·스크롤·확대에서도 동작한다. 문서/전체 레이아웃은 이동 중 변경하지 않는다. Esc·포인터 취소·캡처 상실·포커스 이탈·제자리로 돌아온 드래그에는 이력이나 크기 변경을 남기지 않는다.
- 확정 시 기존 개체 앵커 변환과 보호 검사, 단일 실행 취소, 복구 저장을 그대로 사용한다. 경계 두 번 클릭 자동 맞춤도 유지한다.

Excel 동작의 근거: Microsoft의 [일반 형식](https://support.microsoft.com/en-us/excel/reset-a-number-to-the-general-format), [폭 부족 시 #####](https://support.microsoft.com/en-US/Excel/how-to-correct-a-error), [열 경계 조절·자동 맞춤](https://support.microsoft.com/en-us/excel/change-the-column-width-and-row-height). 실제 Microsoft Excel/물리 DeX 장치에서의 대조 검사는 수행하지 않았다.

## 검사

- 단위 검사: 544개 중 543 통과, Windows 전용 1개 건너뜀. 숫자 폭·고정 형식·지수의 부호와 자릿수·표시 캐시 검사 포함.
- `tests/android-number-width.mjs`: 수정 전/후 동일한 10만 셀 파일, 숫자 앞자리 잘림, 통화·날짜·백분율·수식·텍스트·병합·필터, 실제 마우스 조절·행 높이·undo/redo·4개 취소 경로·제자리 복귀·자동 맞춤·150% 확대·숨긴 행/열·고정/스크롤·복구 후 다시 열기·다른 파일 전환 보호·스마트폰/전체화면과 데스크톱 분리 통과.
- 수정 후 60개 포인터 이동 처리 0.2ms, 드래그 중 그리드 DOM 교체 0회, 문서 너비는 놓기 전 원래 값 유지. 이 측정은 로컬 Chrome의 합성 연속 이벤트 처리 시간이며 Android 장치 성능 보장은 아니다.
- `tests/viewer-modes.mjs` 8개 시나리오 그룹 통과. `tests/android-smoothness.mjs` 지연된 작업 스레드에서 59프레임, 계산 중 문구 0회, 기존 수식 결과 유지.
- `tests/ui-dimensions.mjs` 실제 격리 Electron 검사 통과: 기존 데스크톱의 실시간 조절·캡처·취소·undo/redo·자동 맞춤·확대·고정 창·숨김·복구 유지.

재현/측정 JSON과 스크린샷은 `test-results/android-number-width/`에 보관한다. 실제 Android 네이티브 검사와 APK 정보는 확정 후 이 문서에 추가한다.
