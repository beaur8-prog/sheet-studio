# Sheet Studio 0.7.38 — Excel 비교 계획 후속 개선

개발본의 검증을 마쳤으며 아직 공개 배포하지 않았습니다. [4시간 작업 기록](../EXCEL-FOUR-HOUR-20261105.md), [전체 개선 계획](../EXCEL-BEHAVIOR-IMPROVEMENT-PLAN.md)을 이어서 진행합니다.

## 변경

- 외부에서 수정한 피벗을 오래된 앱 설정으로 덮어쓰지 않습니다. 기본 원본 피벗의 결과·정의·캐시와 숫자 형식을 보존하며, 명시적인 일반 범위 변환과 실행 취소를 지원합니다. 이동한 구형 피벗과 외부에서 고친 0행 정적 결과도 옛 설정으로 되돌리지 않습니다.
- 앱 피벗의 새로 고침에서 항목별 서식·크기를 유지하는 옵션을 추가했습니다. 보고서 필터가 있는 파일의 숫자 형식·행 위치·조건부 서식 범위를 반복 저장할 때도 유지합니다.
- 찾기·바꾸기의 대소문자 처리를 통일하고 선택/시트/통합 문서 범위, 표시 값/수식 원문, 전체 일치, 결과 이동과 변경 미리 보기를 추가했습니다. 여러 시트 변경을 먼저 검증하고 한 번에 실행 취소합니다.
- **도움말 → 파일 호환성**과 상태 표시줄에서 판별한 지원 범위·손실 가능 항목을 확인합니다. 유지하지 못하는 기능이 있으면 XLSX 저장 전 안내하고 기능 제외 사본을 제공합니다. 원본 경로·같은 파일의 연결에는 덮어쓰기를 차단합니다. 원본 위치를 확인할 수 없는 경우 기존 파일 대신 새 사본 이름을 사용합니다.
- 한글 조합 중 대화상자의 Enter/Esc가 적용·닫기를 실행하지 않도록 보강했습니다. 대화상자의 최초 포커스·Tab 이동과 닫은 뒤 셀 입력 복귀를 개선했습니다.
- XLOOKUP의 첫 인수 생략을 숫자 0과 구분하여 문서화된 빈 셀 검색을 처리합니다. 일반 범위와 전체 행·열 경로를 함께 점검합니다.
- 표 바로 오른쪽 입력과 표 관리의 오른쪽 범위 확장을 지원합니다. 기존 열 ID·계산식·메모·필터를 유지하며 새 열도 계산 열·필터·실행 취소와 XLSX 저장에 연결합니다.
- 차트 삽입·설정에 작업 스레드 기반 그림과 데이터 구성 미리 보기를 추가했습니다. 빈 셀의 간격/0/선 연결을 유형에 맞춰 설정하고 기본 원본 차트에도 보존합니다. 오류·빈 텍스트를 임의로 0으로 바꾸지 않습니다.
- 백분율 입력의 표시 자릿수를 유지하며 일반/텍스트 형식 변경을 존중합니다. 날짜 서식만 있는 빈 셀이 저장 후 0으로 바뀌던 오류를 고쳤습니다.
- 입력 도중 배열 계산이 끝나 결과 셀이 된 경우, 거부된 편집 상태가 남아 다음 파일 열기를 막던 문제를 고쳤습니다. 배열 밖의 정상 한글 입력은 유지합니다.
- XLSX 글꼴 요소 순서를 Open XML 스키마에 맞추고 속성·서식 ID를 유지합니다. 독립 SDK의 36개 파일 검사에서 순서 오류가 없음을 확인했습니다.
- 함수 개수는 카탈로그를 기준으로 문서와 동기화합니다. `npm run docs:check`, `npm run docs:functions`를 제공합니다.

## 검증 상태

[전체 편집 회귀](https://github.com/beaur8-prog/sheet-studio/actions/runs/41969864297)의 Windows·Mac·Ubuntu 검사와 [마지막 알림 UI 집중 검사](https://github.com/beaur8-prog/sheet-studio/actions/runs/41973038531)를 통과했습니다. 최종 소스의 단위 검사는 Windows 473개, Mac·Ubuntu 472개 통과·Windows 전용1개 제외, 업데이트 엔진은 29개씩 통과했습니다. Mac 완성 앱의 새 기능·복구·100만 셀 가로/세로·혼합 문서20회, 합성 XLSX 240회 왕복·독립 SDK36파일·LibreOffice7사례를 확인했습니다. [세부 결과와 남은 범위](../EXCEL-FOUR-HOUR-20261105.md)에 조건과 제한을 기록했습니다.

새 Microsoft Excel/VBA 실행 검증은 수행하지 않았습니다. 실제 IME와 화면 읽기 프로그램의 검증도 합성 이벤트/자동 검사와 구분합니다. 공개 릴리스·리토스 페이지는 별도 배포 요청 때 갱신합니다.
