# Sheet Studio v0.7.10 — 편집 가능한 표 교환과 셀 서식

Sheet·Word·Slide Studio 사이에서 표를 복사하고 편집할 수 있습니다. 셀 서식 창과 우클릭 메뉴 닫힘 수정도 포함합니다. 세 앱은 Sheet 0.7.10 / Word 1.2.11 / Slide 1.6.1로 함께 업데이트하세요.

## 다운로드와 설치

- Mac Apple Silicon: `Sheet-Studio-0.7.10-macOS-arm64.dmg`를 열어 앱을 응용 프로그램으로 복사합니다. ZIP도 제공합니다.
- Windows x64: `Sheet-Studio-0.7.10-Windows-x64-Setup.exe`로 설치하고 시작 메뉴에서 실행합니다. 설치된 앱을 작업표시줄에 고정할 수 있습니다.
- Linux x64: `sudo apt install ./Sheet-Studio-0.7.10-Linux-amd64.deb` 후 앱 목록 또는 `sheet-studio`로 실행합니다.

Mac Intel 빌드는 제공하지 않습니다. Node.js나 Excel을 별도로 설치할 필요가 없습니다.

## 변경 내용

- 범위 복사에 HTML 표와 TSV를 함께 기록합니다. Word 본문·Slide 빈 공간에 붙이면 이미지가 아닌 편집 가능한 표가 됩니다.
- Sheet↔Word, Sheet↔Slide, Word↔Slide의 여섯 방향을 지원합니다. 병합·빈 셀·열 너비·글꼴·색·테두리·줄바꿈을 전달합니다.
- 외부 표의 수식 모양 글자는 실행하지 않습니다. 앱을 건너가는 수식은 표시값으로 전달합니다. 같은 Sheet 앱 내부의 수식 복사는 유지합니다.
- 선택·문서가 바뀐 비동기 붙여넣기는 취소하고, 잘못된 병합과 UTF-8 10 MB 제한을 검사합니다.
- 우클릭 → 셀 서식 및 ⌘1/Ctrl+1: 테두리 위치·선 종류·색, 표시 형식·맞춤·글꼴·채우기와 적용·취소를 제공합니다.
- 셀 선택 변경·바깥 클릭·스크롤·Esc·창 전환 시 우클릭 메뉴가 닫힙니다. 빈 셀의 테두리도 XLSX에 저장·복원합니다.

## OS 경고와 제한

Mac 앱은 Developer ID 서명·공증되지 않았고 Windows 설치 파일은 Authenticode 미서명입니다. 다운로드 시 위험한 파일·일반적으로 다운로드되지 않는 파일 경고가 뜰 수 있습니다. 출처를 확인하고 실행하기로 했다면 Windows의 PC 보호 화면에서 **추가 정보 → 실행**으로 진행하세요. 조직 정책·Smart App Control로 실행이 차단되면 관리자에게 문의하세요. 악성코드 탐지는 단순 미서명 경고와 구분해야 합니다.

Slide의 점선·파선·이중선은 현재 모델에서 실선으로 변환됩니다. 앱 간 이동은 실시간 원본 연결이 아니며, 실제 Microsoft Excel/VBA·Word·PowerPoint와의 완전한 호환성을 뜻하지 않습니다. 실제 Windows Excel/VBA 검증은 수행하지 않았습니다. Mac에서 세 패키지의 실제 OS 클립보드 여섯 방향을 검사했고, 각 플랫폼 패키지 검사 결과는 릴리즈 검증 기록에 남깁니다.
