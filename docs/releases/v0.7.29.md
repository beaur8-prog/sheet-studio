# Sheet Studio 0.7.29 — 개발·미배포

Excel 비교 감사에 따라 표·수식·차트의 계산 정확성과 XLSX 원본 보존을 보강했습니다. 공개 릴리즈·리토스 공유본은 별도의 배포 요청 전까지 갱신하지 않습니다. 현재 공개 0.7.28에는 아래 개선이 포함되지 않습니다.

| 영역 | 주요 변경 |
|---|---|
| Excel 표 | Table 생성·관리, 계산 열·요약 행·행 확장, 구조화 참조, 이름/열 변경과 참조 갱신, 표별 정렬·필터, 일반 범위 변환 |
| 수식 | F9 재계산, 긴 참조 의존관계, 전체 행/열의 희소 집계·조회, LET, 이름 관리자, 날짜 조건·1904 체계, 기존 저장 배열의 현재 결과와 편집 보호 |
| 값·표시 | 실제 오류와 같은 글자의 텍스트 구분, 사용자 표시 코드/TEXT, 텍스트 형식 입력, Normal·행·열 서식과 글자별 서식·링크 보존 |
| 차트 | 숨김/필터·현재 오류값, 혼합 누적·거품 크기·원형 색/백분율·날짜 간격, 값 축 범위/눈금/로그/표시 형식, 차트 전용 시트, 셀 변경에 따른 차트·이미지 배치 |
| 편집·대용량 | 자료 구간 정렬과 행 기본 서식 이동, 여러 행열의 작업 스레드 변경과 경계 데이터 보호, 긴 원문 복제 전 한도 검사와 대량 채우기, 확대 상태의 마지막 행, 범위 내 Tab/Enter·데이터 끝 이동, 문서 간 서식 복사와 직접 서식 초기화 |
| XLSX·인쇄 | 입력 제한/보호·미지원 조건부 서식·배열/이름·표/연결·이미지/도형·인쇄 설정·작성 정보 보존, 선택/시트/차트 인쇄와 PDF |

사용법은 [표](../TABLES.md), [수식](../FUNCTIONS.md), [차트](../CHARTS.md), [사용자 가이드](../USER-GUIDE.md), [대용량 범위](../CAPACITY.md)에 정리했습니다. 문제 재현·원인·수정·동일 시나리오의 재검사 내역은 [34차 작업 기록](../EXCEL-IMPROVEMENTS.md)을 확인하세요.

## 검증 범위와 남은 제한

Mac의 실제 Electron 앱과 OOXML/ExcelJS 파일 모델을 검사했고, Windows·Linux·Mac CI의 기존/새 편집 시나리오·100만 셀·설치 패키지 검사를 모두 통과했습니다. 단위 검사는 Windows 337개, Mac·Linux 각각 336개 통과 및 Windows 전용 1개 제외입니다. 최종 실행 근거는 [검증 기록](../../VALIDATION.md)에 있습니다. 이전 Excel에서 수집한 계산 회귀 자료를 재사용하지만 이번에 실제 Windows Excel/VBA를 새로 실행한 것은 아닙니다.

동적 스필 FILTER/SORT/UNIQUE/SEQUENCE, 범용 LAMBDA, 모든 고급 차트의 동일한 렌더링·편집, 외부 연결 새로 고침은 미지원입니다. LibreOffice 26.8의 중첩 LET 재계산에서 한 식의 차이를 관찰했으며 독립 프로그램 간 완전한 계산 일치는 보장하지 않습니다. 일부 XLSM의 표·이름·배열·상세 축/서식 편집은 기존 Windows 저장 경로가 지원하지 않아 Excel 또는 XLSX 사본을 사용해야 합니다.

문서 전체 한도는 기록된 100만 셀, 한 번의 선택 편집·표 변환/계산 열은 10만 셀입니다. 인쇄는 한 번에 2만 셀까지이며 차트·이미지를 셀 뒤에 이어서 배치합니다. 원래 Excel 인쇄 설정을 파일에 보존하는 것과 앱의 A4 PDF 배치가 동일하다는 의미는 아닙니다. 실행 취소는 최대 60단계/추정 128MiB이며 한 번의 큰 변경이 한도를 넘으면 기록 정리 안내를 표시합니다.

설치 파일 공개 시 Windows 미서명·Mac 미공증 경고 안내, Windows ‘추가 정보 → 실행’ 절차, Windows 우선 표시와 Mac Apple Silicon 전용 제공을 유지해야 합니다. 이번 개발에서는 공개 링크를 바꾸지 않습니다.
