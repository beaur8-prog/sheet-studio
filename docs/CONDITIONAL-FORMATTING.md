# 조건부 서식

**색조·기본 데이터 막대 편집은 0.7.39 개발 버전에 추가했으며 아직 공개 배포되지 않았습니다.**

범위를 선택하고 **홈 → 조건부 서식 → 새 규칙**을 누른다. 기존 비교·텍스트·중복·상위/하위·평균·수식 규칙 외에 **색조 (2색 / 3색)**와 **데이터 막대 (그라데이션)**를 선택할 수 있다. 적용·편집·우선순위 변경·삭제는 실행 취소할 수 있다. 적용 전 창을 닫으면 바꾸지 않는다.

## 색조

최소·중간·최대 기준과 색을 정한다. 2색은 중간 기준을 사용하지 않는다. 숫자·백분율·백분위수 기준을 지원하며 최저·최고는 범위 내 숫자의 최솟값·최댓값을 사용할 수 있다.

- **백분율 50:** 최솟값과 최댓값 사이의 중간 숫자.
- **백분위수 50:** 자료를 정렬한 분포의 중간. 예를 들어 `0, 1, 2, 100`에서는 1.5이므로 백분율의 50과 다르다.
- 빈 셀·텍스트·논리값·오류는 분포에서 제외한다. 숫자인 수식 결과와 스필 결과는 포함한다. 숨김·필터 상태와 관계없이 지정한 범위의 숫자로 계산한다.
- 숫자가 전부 같으면 첫 색으로 표시한다. 기준점이 실행 시 뒤집히면 표시하지 않는다. 이 경계 동작의 실제 Excel 대조는 대기다.

높은 우선순위의 채우기와 일반 규칙의 ‘참이면 다음 규칙 중지’를 따른다. 색조 자체에는 중지 옵션을 사용하지 않는다. 원래 셀의 값과 기본 서식은 바꾸지 않는다.

## 기본 데이터 막대

최소·최대 기준과 막대 색을 정한다. **기본 OOXML 그라데이션 규칙**의 문서화된 계산으로 셀 너비의 10%부터 90%까지 채운다. 숫자가 같으면 90%로 표시한다. 음수도 지정한 최소·최대 구간 안에서 길이를 계산한다. 이 방식은 음수 전용 색·가운데 축을 사용하는 고급 막대와 구별한다.

화면과 인쇄는 같은 계산·그라데이션을 사용하고, XLSX에는 실제 `dataBar` 규칙을 기록한다. 값은 계속 표시한다. 단색, 음수 전용 색, 가운데 축, 방향, 테두리, 별도 길이, 값 숨김은 이번 작성 범위에 포함하지 않는다. 실제 Excel에서 기본 막대를 새로 여는 모습과 모두 같은지 직접 실측하지 않았다.

## 가져온 규칙 보존

지원하는 기본 색조·막대는 편집할 수 있다. 아이콘 집합, 수식 기준점, 고급 `x14` 막대는 원본 보존 대상으로 둔다. 고급 막대의 기본 규칙 연결 ID와 확장 정의를 함께 보존하고, 행·열 변경과 시트 이름 변경 시 범위·수식을 함께 갱신한다. 일부 미지원 규칙이 섞여 있으면 원본이 저장되므로 개별 편집은 차단한다. **모두 지우기**는 확장 정의까지 지우며 실행 취소할 수 있다.

XLSM에서 색조·막대 규칙의 편집은 제한한다. 원본은 Excel에서 바꾸거나 XLSX 사본을 다시 열어 편집한다. 셀 값 변경에 따른 재계산과 원본 규칙 보존은 유지한다.

범위는 규칙당 100,000셀, 규칙은 시트당 200개까지 지원한다. 반복 저장 검사·독립 OOXML 검사는 Excel의 실제 실행·복구 경고 검사를 대신하지 않는다.
