# 핵심 개선 계획 — 2026-10-30

기준: `180522e` / Sheet Studio 0.7.29. 우선순위는 계산·Excel 파일 호환성 → 동적 배열 → 인쇄·PDF다. 이번 요청은 계획 수립과 개발 착수이며, 공개 릴리즈와 리토스 공유본 갱신은 별도의 “배포해줘” 요청 때 수행한다.

## 1. 계산과 Excel 파일 호환성

- 재현 파일과 기대 결과를 먼저 만든다. 숫자·문자·논리값·빈 셀·오류, 날짜 체계, 배열 수식, 표·차트·이름 정의를 함께 검사한다.
- 열기 → 수정 → 실행 취소/다시 실행 → 저장 → 다시 열기에서 값·수식·서식·지원하지 않는 원본 정보가 유지되는지 확인한다.
- 우선 인쇄 영역·반복 제목·용지 설정처럼 파일에는 보존되지만 앱 동작에는 연결되지 않은 정보를 연결한다. 계산 결과의 변경은 공식 Excel 규칙 또는 기존 Excel 측정 자료로 판단한다.
- 완료 기준: 새 재현 사례 통과, 기존 단위/관련 UI 검사 통과, XLSX 반복 왕복 후 의미 유지. 실제 Microsoft Excel 실행 결과와 독립 엔진 검증은 구분한다.

## 2. 동적 배열

- FILTER, SORT, UNIQUE, SEQUENCE 계산을 추가한다. 가로·세로·2차원, 중첩 함수, 빈 결과, 오류와 인수 경계를 검사한다.
- 결과의 자동 확장·축소, 막힌 영역의 `#SPILL!`, 원본 셀 변경과 재계산, 결과 셀 편집 제한, `A1#` 참조를 연결한다.
- 시작 셀 수식과 파생 결과를 분리해 실행 취소와 대용량 문서의 복제 비용을 제한한다. 기존 고정 배열(CSE)과 동적 배열을 구분해 XLSX로 저장한다.
- 완료 기준: 직접 입력 → 결과 표시 → 원본 변경 → 실행 취소/다시 실행 → 복사 → XLSX 저장/재열기 시나리오 통과. 함수 계산만 구현한 상태를 동적 배열 전체 지원으로 표기하지 않는다.

## 3. 인쇄와 PDF

- 저장된 인쇄 영역, 반복 행·열, 용지·방향·여백·배율, 수동 페이지 나눔을 페이지 계산에 반영한다.
- 페이지마다 반복 제목과 머리글·바닥글을 표시하고 차트의 시트상 위치를 유지한다. 선택 영역과 차트 전용 인쇄를 함께 확인한다.
- 설정 UI와 XLSX 왕복을 연결하고 PDF를 실제 렌더링해 잘림·겹침·페이지 수를 검사한다.
- 완료 기준: 여러 페이지 표, 가로/세로, 숨긴 행·열, 병합 셀, 차트, 반복 제목의 PDF 시각 검증과 관련 회귀 검사 통과.

## 진행 방법과 범위

각 단계는 재현 → 수정 → 같은 시나리오 재검증 → Git 반영 순서로 진행한다. Windows Excel/VBA의 새 실행 검증은 현재 환경에서 수행할 수 없으며, LibreOffice 비교는 보조 진단으로 사용한다. 고급 매크로 실행, 외부 연결, LAMBDA 전체 구현은 위 세 단계의 완료 조건에 포함하지 않는다.

## 1차 수정 — 0.7.30 개발

재현: `worksheetExtrasFixture`의 인쇄 영역은 A1:C20이지만 기존 출력은 값이 있는 셀만 기준으로 A1:B2를 출력했고, 영역 밖의 먼 셀이 있으면 큰 범위 오류가 났다. 반복 제목과 원본 여백도 무시했다. 원인은 원본 XML 보존 경로와 실제 HTML 인쇄 경로가 분리되어 있었기 때문이다.

수정: 시트 로컬 `Print_Area`/`Print_Titles`와 페이지 설정을 해석해 표시 행·열의 크기로 페이지를 계산한다. 불연속 영역, 반복 행·열, 가로/세로 용지와 여백, 백분율·페이지 맞춤, 수동 나눔, 페이지 진행 순서를 반영한다. 반복 제목이 페이지 수를 늘리는 경우도 맞춤 배율에 포함한다. 제목을 포함한 분량과 최대 페이지 수에 제한을 둔다. 잘못된 참조는 전체 시트로 조용히 대체하지 않고 오류를 표시한다.

선택 출력은 저장된 인쇄 영역·반복 제목을 무시한다. 인쇄창에 영역 사용 여부를 추가했다. 병합 내용이 페이지 경계에서 복제되는 문제와 테두리 때문에 각 행의 높이가 늘어 페이지 끝이 잘리는 문제를 함께 수정했다. 사용자 통합 문서나 프린터 설정을 변경하지 않는다.

다음 차수는 1단계의 계산·파일 왕복 경계 사례를 계속 보강하고, 2단계의 동적 배열을 엔진·편집·파일 저장까지 함께 연결한다. 머리글/바닥글, 차트의 원래 시트 위치와 페이지 설정 편집 UI는 3단계에 남아 있다. 이번 변경으로 세 우선순위 전체가 완료된 것은 아니다.

근거: [인쇄 영역](https://support.microsoft.com/en-us/excel/set-or-clear-a-print-area-on-a-worksheet), [반복 제목](https://support.microsoft.com/en-us/excel/repeat-specific-rows-or-columns-on-every-printed-page), [페이지 맞춤과 수동 나눔](https://support.microsoft.com/en-au/excel/scale-a-worksheet), [페이지 순서](https://support.microsoft.com/en-au/excel/page-setup).

검증 결과: [최종 CI](https://github.com/beaur8-prog/sheet-studio/actions/runs/41071955387), [상세 기록](../VALIDATION.md). 최종 앱 소스는 `8a900e9`이며 뒤의 문서 정리 커밋은 앱 코드를 바꾸지 않는다.
