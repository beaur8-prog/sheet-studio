# 찾기·바꾸기

**0.7.38 개발 기능이며 아직 공개 설치 파일에는 포함되지 않습니다.**

상단 **찾기 및 바꾸기**, 홈의 **찾기 및 선택**, Windows/Linux의 **Ctrl+F** 또는 Mac의 **⌘F**로 창을 엽니다.

## 범위와 검색 대상

| 설정 | 동작 |
|---|---|
| 현재 시트 | 창을 연 시트의 셀을 찾습니다. |
| 선택 영역 | 창을 열기 직전 선택한 범위에서 찾습니다. 결과로 다른 셀에 이동해도 처음 범위를 사용합니다. |
| 통합 문서 | 여러 시트에서 찾습니다. 숨긴 시트는 별도 옵션으로 찾기·바꾸기 대상에 포함합니다. 결과 위치로 이동하려면 해당 시트를 먼저 표시하세요. 차트 전용 시트는 제외합니다. |
| 값·수식 원문 | 입력한 값과 수식 자체를 찾고 바꿉니다. 예: `=SUM(A1:A3)`의 `SUM`. |
| 표시 값 | 계산·표시 형식을 적용한 화면 내용을 찾습니다. 검색 전용이며 수식 결과를 덮어쓰지 않습니다. |

`12.5%`로 보이는 셀이 파일 안에서는 `0.125`로 저장되어 있을 수 있습니다. 보이는 문자열을 찾으려면 **표시 값**을 사용하세요. 대소문자 구분과 셀 내용 전체 일치를 선택할 수 있습니다. `*`·`?` 등은 와일드카드로 해석하지 않고 입력한 문자 그대로 찾습니다.

## 찾아서 이동하기

1. 찾을 내용과 조건을 정한 뒤 **모두 찾기 / 미리 보기**를 누릅니다.
2. 결과의 시트·셀 버튼을 누르거나 **다음 찾기**로 이동합니다.
3. 검색 조건을 바꾸면 다시 찾습니다. 바꾸기는 새 조건의 미리 보기를 먼저 요구합니다.

검색은 전체 범위를 세지만 목록에는 처음 100개를, 다음 찾기에는 처음 1,000개를 제공합니다. 결과가 더 많으면 범위를 좁혀 확인하세요.

## 여러 셀을 한 번에 바꾸기

1. 검색 대상을 **값·수식 원문**으로 선택하고 바꿀 내용을 입력합니다.
2. **모두 찾기 / 미리 보기**로 전체 발견 수와 변경 예를 확인합니다.
3. **모두 바꾸기**를 누릅니다. 조건 변경 뒤 바로 누른 경우에는 먼저 미리 보기만 만들고 다시 누르도록 안내합니다.
4. 창을 닫은 뒤 **실행 취소** 한 번으로 셀 변경 전체를 되돌릴 수 있습니다. 창 안의 입력란에서 Ctrl/⌘Z를 누르면 해당 입력란의 텍스트 편집을 취소합니다.

모두 바꾸기는 목록에 보이는 셀만 바꾸는 명령이 아닙니다. 지정한 전체 범위를 검사하며 **한 번에 변경할 수 있는 셀은 최대 100,000개**입니다. 숫자·문자·수식이 의도대로 바뀌는지 미리 보기에서 확인하세요.

보호된 셀, 배열 일부, 편집할 수 없는 피벗 결과, 잘못된 표 머리글·참조, 입력 제한 또는 문서 한도 위반이 있으면 **전체를 변경하지 않고 원인을 표시**합니다. 여러 시트 중 일부만 먼저 바뀌지 않습니다. 입력 제한의 경고·정보 규칙도 일괄 작업에서 자동으로 무시하지 않습니다.

검증 범위와 Excel 대조 대기 항목은 [4시간 개선 결과](EXCEL-FOUR-HOUR-20261105.md)에 있습니다.
