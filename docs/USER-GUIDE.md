# Sheet Studio 사용자 가이드

> **Windows 설치 안내: ‘실행 안 함’ 버튼만 보일 때**
> 설치 파일을 열었을 때 ‘Windows의 PC 보호’ 화면에 ‘실행 안 함’ 버튼만 보이면 **‘추가 정보’를 먼저 누르세요.** 그러면 **‘실행’ 버튼이 나타납니다.** ‘실행’을 누르면 설치가 시작됩니다.

> **다운로드·설치 전 안내:** 현재 Mac 앱은 Apple Developer ID 서명·공증을 받지 않았고, Windows 설치 파일은 코드 서명(Authenticode)이 되어 있지 않습니다. 따라서 다운로드 후 설치하거나 처음 실행할 때 운영체제의 보안 경고가 표시되거나 실행이 차단될 수 있습니다. 경고 표시 여부는 OS 버전과 보안 설정에 따라 다릅니다. 다운로드 출처를 확인하고, 회사·기관 PC에서는 관리자 정책을 따르세요.

## 1. 어떤 앱인가요?

Sheet Studio는 한국어 리본 UI를 갖춘 로컬 스프레드시트 앱입니다. 표 작성, 수식 계산, 서식, 필터, 차트, 피벗테이블과 XLSX/CSV 파일 교환을 지원합니다. Excel의 익숙한 작업 흐름을 독립적으로 구현했으며 Excel 전체 기능과 호환성을 보장하는 제품은 아닙니다.

| 기능 | 할 수 있는 일 |
| --- | --- |
| 셀·시트 편집 | 직접 입력, 복사·붙여넣기, 채우기, 병합, 시트 추가·복제·이름 변경 |
| 수식 | 379개 함수 이름, 자동 합계, 함수 검색·완성, 다른 시트 참조 |
| 데이터 분석 | 정렬, 자동 필터, 조건부 서식, 차트 10종, 피벗테이블 |
| 파일 | XLSX·CSV 읽기/쓰기, 앱 문서 JSON 저장·복원 |
| VBA 연결 | Windows에 설치된 Excel을 이용하는 기존 XLSM 작업 흐름 |

## 2. 다운로드와 설치

[릴리즈의 Assets](https://github.com/beaur8-prog/sheet-studio/releases/tag/v0.7.17)에서 운영체제에 맞는 파일을 받으세요. 아래 배포 패키지에는 실행 환경이 포함되어 **Node.js를 따로 설치할 필요가 없습니다.** GitHub가 자동 생성하는 `Source code` ZIP은 실행 앱이 아닙니다.

| 컴퓨터 | 다운로드 파일 |
| --- | --- |
| Windows 64비트 x64 | `Sheet-Studio-0.7.17-Windows-x64-Setup.exe` |
| Mac Apple Silicon (M1/M2/M3/M4 등) | `Sheet-Studio-0.7.17-macOS-arm64.dmg` 또는 `.zip` |
| Linux Ubuntu·Debian 계열 x64 | `Sheet-Studio-0.7.17-Linux-amd64.deb` |

### Mac

1. Apple 메뉴 → **이 Mac에 관하여**에서 칩을 확인합니다. Mac 배포본은 Apple Silicon(M 시리즈, arm64)용입니다.
2. Apple Silicon용 DMG를 열고 **Sheet Studio.app**을 **응용 프로그램(Applications)** 폴더로 복사합니다. ZIP은 압축을 풀어 `.app` 전체를 복사합니다.
3. 복사한 앱을 실행합니다. DMG는 복사 후 추출해도 됩니다.
4. 다음부터는 응용 프로그램 폴더 또는 Spotlight에서 **Sheet Studio**를 실행합니다.

이 릴리즈의 Mac 앱은 로컬 ad-hoc 서명이며 Apple Developer ID 서명·공증을 받지 않았습니다. 따라서 macOS가 실행을 차단할 수 있습니다. 다운로드 출처를 확인하고 macOS의 보안 안내에 따라 사용자가 실행 여부를 결정해야 합니다. 회사 정책으로 차단된 경우 관리자에게 문의하세요. 보안 기능을 일괄 해제하는 명령은 필요하지 않습니다.

### Windows

1. `Sheet-Studio-0.7.17-Windows-x64-Setup.exe`를 다운로드합니다.
2. Setup EXE를 실행하고 한국어 또는 영어를 선택합니다. 설치 마법사에서 경로를 확인하거나 변경한 뒤 설치합니다. 기본 경로는 `%LOCALAPPDATA%\Programs\Sheet Studio`입니다. 시작 메뉴와 바탕화면에 **Sheet Studio** 바로가기가 생성됩니다.
3. 시작 메뉴에서 Sheet Studio를 실행한 뒤 작업표시줄 아이콘을 우클릭해 **작업 표시줄에 고정**을 선택합니다.
4. 이전 포터블 버전의 고정 아이콘은 먼저 고정 해제하세요. 설치 파일(Setup EXE) 자체를 고정하지 마세요.

**Windows 다운로드·설치 경고 안내**

- 다운로드할 때 브라우저가 “위험한 파일”, “일반적으로 다운로드되지 않는 파일” 등의 경고를 표시할 수 있습니다. 경고 문구는 브라우저와 보안 설정에 따라 다릅니다. 이 페이지에서 받은 파일인지와 파일명·체크섬을 확인하세요. 경고가 없거나 미서명이라는 이유만으로 파일의 안전성이 보장되는 것은 아닙니다.
- 설치 파일을 실행할 때 **“Windows의 PC 보호”** 화면이 나타날 수 있습니다. 배포 출처를 확인하고 실행하기로 결정했다면 **추가 정보 → 실행**을 누르면 설치를 진행할 수 있습니다.
- **추가 정보**를 누른 뒤에도 **실행** 버튼이 없거나 회사·기관의 보안 정책으로 차단된 경우 관리자에게 문의하세요. 악성코드가 탐지되었다는 경고는 위의 미서명·평판 경고와 다르므로 실행하지 마세요.

Windows 패키지는 Authenticode 서명되지 않았습니다. SmartScreen이나 조직 보안 정책이 경고 또는 차단할 수 있습니다. 배포 저장소와 파일명을 확인하고 조직 정책을 따르세요. 기본 표 편집에는 Microsoft Excel 설치가 필요하지 않습니다. VBA 연결에만 Windows 데스크톱 Excel이 필요합니다.

### Linux (Ubuntu·Debian 계열 x64)

`Sheet-Studio-0.7.17-Linux-amd64.deb`를 다운로드한 폴더에서 설치합니다.

```sh
sudo apt install ./Sheet-Studio-0.7.17-Linux-amd64.deb
sheet-studio
```

한글이 네모로 표시되는 환경에서는 `sudo apt install fonts-noto-cjk`로 한글 글꼴을 설치하고 앱을 다시 실행하세요.

설치 후 앱 목록의 **Sheet Studio**로도 실행할 수 있습니다. 앱은 일반 사용자로 실행하세요. 업데이트도 새 DEB 파일에 같은 설치 명령을 사용합니다. 삭제는 `sudo apt remove lattice-sheet-studio`입니다.

Ubuntu 22.04 x64 CI의 가상 화면에서 설치 및 앱 UI를 검증합니다. 다른 배포판과 실제 GNOME 데스크톱의 메뉴 조작은 별도 검증하지 않았습니다. ARM64·RPM 패키지는 제공하지 않습니다. Linux에서 Windows Excel/VBA 연결은 지원하지 않습니다. 다운로드한 DEB는 서명된 패키지 저장소를 통한 배포가 아니므로 출처와 SHA-256 체크섬을 확인하세요.

0.7.11부터 앱 메뉴와 실행 창이 같은 `sheet-studio.desktop` 항목을 사용하며, 일반적인 아이콘 크기를 함께 설치합니다. Ubuntu 22.04·24.04에서 설치·아이콘 조회·X11 및 중첩 Weston Wayland 창 식별자를 검사했습니다. 실제 GNOME Dock 메뉴 클릭은 별도 수동 검증하지 않았습니다. 업데이트 후에는 실행 중인 이전 앱을 종료하고 앱 목록에서 **Sheet Studio**를 다시 실행하세요. Ubuntu Dock에서 해당 아이콘을 우클릭해 **Dash에 고정 / Pin to Dash**를 선택합니다. 실행 파일이나 설치 파일을 직접 고정하는 방식이 아닙니다.

### 업데이트

작업 문서를 먼저 `.sheet.json` 또는 `.xlsx`로 저장하고 앱을 종료합니다. 새 Mac 앱으로 기존 앱을 교체하거나 새 Windows Setup EXE를 실행해 업데이트합니다. 자동 저장은 파일 백업을 대신하지 않습니다. 기존 버전은 아래 변경 내역의 소스 이력이며, 모든 버전의 실행 파일이 공개된 것은 아닙니다.

## 3. 처음 실행하고 표 만들기

1. 처음 실행하면 빈 통합 문서가 열립니다. 이전 작업이 있으면 기기의 자동 저장 상태를 복원합니다.
2. A1에 `품목`, B1에 `금액`, A2에 `커피`, B2에 `3000`, A3에 `차`, B3에 `2500`을 입력합니다.
3. B4에 `=SUM(B2:B3)`을 입력하고 Enter를 누릅니다. `5500`이 표시됩니다.
4. B2:B4를 선택하고 홈의 통화·숫자 서식을 적용합니다.
5. **파일 → XLSX 저장**으로 문서를 저장합니다.

**도움말 → 예제 통합 문서**에서는 수식·서식이 포함된 예제를 엽니다. 현재 작업이 있다면 먼저 파일로 저장하세요.

## 4. 화면과 편집

| 영역 | 용도 |
| --- | --- |
| 상단 통합 문서 제목 | 문서 이름 변경 |
| 리본 | 홈·삽입·수식·데이터·보기 등 기능 선택 |
| 이름 상자 | `A1` 또는 `A1:C10`을 입력해 셀·범위 이동 |
| 수식 입력줄 | 선택한 셀의 값·수식 확인과 편집 |
| 아래 시트 탭 | 시트 이동, 더블클릭 이름 변경, 우클릭 복제·삭제 |
| 상태 표시줄 | 저장 상태·선택 통계·확대 비율 확인 |

- 셀을 더블클릭하거나 F2를 눌러 편집합니다. Enter로 확정하고 아래로, Tab으로 확정하고 오른쪽으로 이동합니다. Esc는 입력을 취소합니다.
- 0.7.11부터 셀을 선택하고 바로 글자·숫자를 입력하면 **방향키로 입력을 확정하고 해당 방향의 셀로 이동**합니다. 숨김 행·열은 건너뛰고 병합 셀은 바깥으로 이동합니다. **F2·더블클릭·수식 입력줄**로 편집할 때는 방향키가 글자 사이 커서를 이동합니다. 수식에서 참조를 기다리는 위치의 방향키는 셀 참조를 지정합니다.
- 열·행 머리글 경계를 드래그해 크기를 조절합니다. 경계를 더블클릭하면 자동 맞춤합니다.
- **보기 → 틀 고정**으로 제목 행·열을 고정합니다.
- **홈 → 선택하여 붙여넣기**에서 값·수식·서식만 붙이거나 행과 열을 바꿉니다.
- 시트 삭제는 실행 취소할 수 있습니다. 삭제한 시트의 수식 참조는 `#REF!`가 되며 같은 이름으로 새 시트를 만들어도 되살아나지 않습니다.

셀 범위를 선택한 뒤 **홈 → 글꼴 색(A)** 또는 **우클릭 → 글꼴 색**을 엽니다. 팔레트의 대상 범위를 확인하고 색을 고른 뒤 **적용**을 누르세요. **취소**하면 기존 색을 유지합니다. 채우기 색도 같은 방식이며 실행 취소 한 번으로 되돌릴 수 있습니다.

### 숫자 자동 채우기

`1`, `2`를 나란한 두 셀에 입력하고 두 셀을 선택한 뒤 오른쪽 아래 모서리의 채우기 핸들을 여섯 셀까지 끌면 `1, 2, 3, 4, 5, 6`이 됩니다. 가로·세로와 위·왼쪽 역방향을 지원합니다. `2, 4`는 `6, 8`로, `100, 95`는 `90, 85`로 이어지며 소수·백분율도 지원합니다. 여러 행·열은 각각의 숫자 간격을 사용합니다. 숫자 세 개 이상은 선형 추세를 연장합니다.

숫자 한 개·문자는 반복 복사하며 수식은 상대 참조를 이동해 복사합니다. 숨김 셀은 변경하지 않습니다. Esc는 드래그를 취소하고 적용 후에는 한 번의 실행 취소로 되돌립니다. **⌘D / Ctrl+D**, **⌘R / Ctrl+R**는 숫자 계열 생성이 아닌 아래·오른쪽 복사 명령입니다.

### 셀 서식

범위를 선택하고 **우클릭 → 셀 서식…** 또는 **홈 → 서식 → 셀 서식…**을 엽니다. 테두리 탭에서 선 종류·색을 고른 뒤 윤곽선·안쪽·모든 테두리 또는 개별 위치를 선택하고 **적용**을 누르세요. 표시 형식·맞춤·글꼴·채우기도 함께 설정할 수 있습니다. 취소하면 바뀌지 않으며 적용 내용은 한 번에 실행 취소할 수 있습니다. 자세한 내용은 [워크시트 안내](WORKSHEET.md#셀-서식)를 참조하세요.

## 5. 수식·분석 기능

### 수식

`=`로 시작해 입력합니다. **수식 → 함수 삽입**에서 함수 이름·설명을 검색합니다. 입력 중 함수 후보를 방향키로 고르고 Tab으로 완성할 수 있습니다. 셀을 클릭·드래그해 참조를 지정하고 F4로 상대/절대 참조를 전환합니다. Mac에서 F4가 시스템 기능으로 동작하면 Fn+F4 또는 앱의 Command+T를 사용합니다.

### 정렬·필터·조건부 서식

제목 행을 포함한 범위를 선택한 뒤 **데이터 → 필터**를 켭니다. 머리글 화살표에서 검색·체크박스·조건을 지정합니다. 머리글의 **색 기준 필터**에서는 셀 채우기색·글자색·채우기 없음·자동 글자색을 선택한 뒤 **확인**을 누릅니다. 지원하는 조건부 서식의 표시색과 색이 지정된 빈 셀도 포함하며, 다른 열의 숫자·값 조건과 함께 사용할 수 있습니다. 데이터나 색 변경 후에는 **다시 적용**을 사용합니다. 조건부 서식은 홈에서 규칙을 만들며 지원하는 규칙은 값이나 수식 변화에 따라 갱신됩니다.

### 차트

표 범위를 선택하고 **삽입**에서 차트를 만듭니다. 0.7.11부터 숫자로 된 첫 행·첫 열은 데이터에 포함하며, 문자 제목과 항목명은 자동으로 구분합니다. 숫자 한 열도 선택할 수 있습니다. 연도·번호를 항목명으로 쓰려면 차트 설정의 **첫 열을 항목 이름으로 사용**, 숫자 제목을 쓰려면 **첫 행을 계열 이름으로 사용**을 켜세요. 차트 설정에서 유형·범례·레이블을 바꾸고 테두리 조절점으로 크기를 바꿉니다. XLSX와 앱 문서에 저장할 수 있습니다. 범례는 각 줄을 차트 가운데에 배치하며 차트 크기를 바꾸면 다시 맞춥니다. 긴 이름은 말줄임하고 전체 이름은 마우스를 올려 확인합니다.

가로 한 줄 `A1:D1`의 숫자 네 개도 한 계열의 값 네 개로 읽습니다. 원형·도넛형은 네 조각을 표시합니다. 차트 설정에서 **데이터 계열 방향 → 자동/행/열**을 선택할 수 있습니다. 제목 행과 값 한 행이 있는 표는 자동으로 항목별 값 한 계열로 해석합니다. 한 계열의 세로 막대형은 항목명을 막대 아래에 표시하고 같은 색을 쓰며 중복 범례를 생략합니다. 여러 계열은 색과 범례를 유지합니다. 긴 항목명은 두 줄·말줄임과 전체 이름 툴팁을 제공합니다. 분산형 한 줄은 X값을 1부터 자동 지정하며 거품형은 X·Y·크기 자료가 필요합니다.

### 피벗테이블

제목 행이 있는 원본 범위를 선택하고 **삽입 → 피벗테이블**을 누릅니다. 행·열·값 필드와 집계 방식을 선택합니다. 원본 수정 후 피벗 화면의 **새로 고침**을 누릅니다. 자동으로 항상 재집계되는 것은 아닙니다.

## 6. 파일 저장과 VBA

개발 버전 0.7.19부터 데스크톱 앱의 **열기·저장 창은 현재 문서가 있는 폴더**를 먼저 표시합니다. 다른 폴더에 저장하면 그 폴더를 이어 쓰며, 새 문서는 마지막으로 성공한 열기·저장 위치를 사용합니다. 처음 사용하거나 기억한 폴더가 없으면 문서 폴더를 엽니다. 취소하거나 파일 읽기·쓰기에 실패해도 위치를 바꾸지 않습니다. 앱을 다시 실행해 자동 복구한 문서에도 위치를 유지하며, 경로는 내보내는 문서에 포함하지 않습니다. 브라우저 버전의 다운로드 위치는 브라우저 설정을 따릅니다.

| 형식 | 권장 용도와 제한 |
| --- | --- |
| `.xlsx` | 다른 스프레드시트 앱과 교환. 미지원 개체·서식은 재저장 시 손실될 수 있음 |
| `.csv` | 단순 표 데이터 교환. 서식·차트·여러 시트를 보존하는 문서 형식이 아님 |
| `.sheet.json` | 앱 편집 상태 보관·복원, 다른 기기로 작업 이동 |
| `.xlsm` | 기존 매크로 문서 열기. 변경 내용을 반영한 VBA 보존 저장·실행 연결은 Windows Excel 전용 |

상단의 **이 기기에 저장됨**은 앱의 로컬 자동 저장 상태입니다. OS 계정이나 앱 데이터가 삭제될 수 있으므로 중요한 문서는 파일로 내보내세요. **파일 → 인쇄 / PDF**는 운영체제의 인쇄 흐름을 사용합니다.

Windows VBA 작업은 XLSM 열기 → **개발 도구 → Excel에서 매크로 실행 → Excel 연결** → 실행 → **결과 가져오기** → **XLSM 저장** 순서입니다. Excel 보안 정책을 그대로 따릅니다. Mac Excel VBA 연결은 구현하지 않았습니다. **이번 릴리즈에서 Windows VBA 실행 및 실제 Microsoft Excel과의 왕복 호환성은 검증하지 않았습니다.** 세부 범위는 [VBA 안내](VBA.md)를 확인하세요.

### Word·Slide Studio와 표 복사 (0.7.11)

표 범위를 복사한 뒤 Word Studio 1.2.11의 본문 또는 Slide Studio 1.6.1의 슬라이드에 붙이면 셀을 수정할 수 있는 표가 됩니다. 글자·배경·테두리·병합을 전달하며 수식은 표시값으로 변환합니다. [사용법과 호환 범위](STUDIO-CLIPBOARD.md)를 확인하세요.

## 8. 제한과 문제 해결

0.7.8에서는 숨김 행·열을 범위 편집에서 보호합니다. 병합 셀 일부에 붙여넣기와 병합 영역 정렬은 차단하며, 숨김 셀을 가로지르는 잘라내기 이동도 차단합니다. 피벗 원본이 없어 재계산할 수 없으면 XLSX 사본에 마지막 결과를 일반 셀로 보존합니다. [감사 항목별 수정 결과](../excel-parity-audit/06-RESOLUTION.md)를 확인하세요.

- 동적 배열, 전체 열 수식 `A:A`, Power Query, 공동 편집, 독립 VBA 런타임은 지원하지 않습니다.
- 문서 전체의 기록된 셀과 수식 범위는 최대 1,000,000셀, 선택 편집·붙여넣기·채우기는 한 번에 최대 100,000셀입니다. XLSM 원본·결과 파일은 각각 15 MB 이하이며 Excel 연결의 변경 계획은 200,000셀 이하입니다. [기능별 한도와 저장 안내](CAPACITY.md)를 확인하세요.
- `#REF!`: 삭제된 시트·행·열이나 잘못된 참조를 확인합니다. 의도치 않은 삭제는 실행 취소합니다.
- 저장 공간 부족: `.sheet.json` 또는 `.xlsx`로 즉시 파일 저장합니다.
- XLSM 저장 불가(Mac): 앱 문서로 보관하거나 매크로 제외 확인 후 XLSX 사본을 만듭니다. VBA 보존 편집 저장에는 Windows Excel이 필요합니다.
- 원본 Excel 파일이 중요하면 사본으로 작업합니다. [파일 형식 지원 범위](../IO-NOTES.md)를 확인하세요.

## 9. 소스에서 실행하기

개발자용이며 일반 배포 파일 실행에는 필요하지 않습니다. Node.js 22.12 이상과 Git을 설치합니다.

```sh
git clone https://github.com/beaur8-prog/sheet-studio.git
cd sheet-studio
git checkout v0.7.17
npm ci
npm run runtime:install
npm run desktop
```

브라우저 개발 모드는 `npm run dev` 후 `http://127.0.0.1:5192`에 접속합니다. 네이티브 파일 대화상자와 Windows VBA 연결은 데스크톱 앱 기능입니다.

문서 구성은 [Lithos 기능 및 사용 설명서](https://github.com/beaur8-prog/lithos/blob/main/Lithos_USER_GUIDE.md)의 소개·첫 실행·기능별 설명·단축키·제한 순서를 참고했습니다. 기능과 설치 안내는 Sheet Studio 구현에 맞게 작성했습니다.
