## 0.7.4 수정 상세

- **시트 삭제:** `=Source!A1`이 삭제 후 `=#REF!`로 남습니다. 다른 시트를 Source로 만들어도 기존 계산이 그 시트에 연결되지 않습니다.
- **시트 이름 변경:** 일반 셀 수식과 조건부 서식의 수식을 함께 갱신합니다. 문자열·INDIRECT의 문자열 인수는 그대로 둡니다.
- **시트 탭:** 화면 갱신 때 탭 버튼을 유지해 활성·비활성 시트의 더블클릭 이름 변경이 동작합니다.
- **Mac 빌드:** 생성한 앱의 Finder 메타데이터를 정리합니다. 동기화 폴더의 서명 문제는 `SHEET_STUDIO_OUTPUT_DIR`로 출력 위치를 바꿔 회피할 수 있습니다.
- **회귀 검증:** 단위 테스트 98개 통과, Windows 전용 1개는 Mac에서 건너뜀. macOS arm64 설치 앱에서 삭제·재생성·실행 취소/다시 실행·이름 변경·조건부 서식·재로드를 확인했습니다. 플랫폼별 공개 빌드 결과는 릴리즈 페이지에 기재합니다.

Windows VBA 실행 및 실제 Microsoft Excel의 XLSX/XLSM 왕복 호환성은 이번 릴리즈 검증 범위에 포함하지 않았습니다.
