# 수식 입력과 기본 기능 점검 — 0.4.1

## 자동 합계 사용법

숫자 아래 또는 오른쪽의 결과 셀에서 **홈/수식 → 자동 합계**를 누릅니다. 제안된 `SUM` 범위에 움직이는 파란 점선이 나타나고, 수식의 범위 부분이 선택됩니다. 셀을 클릭하거나 드래그하여 범위를 바꾼 뒤 **Enter로 확정**, **Esc로 취소**합니다. 확정 전에는 셀 값과 자동 저장 문서를 변경하지 않습니다.

숫자 범위를 미리 선택할 수도 있습니다. 한 행이면 오른쪽, 여러 행이면 각 열 아래에 합계를 준비합니다. 마지막 빈 행/열을 함께 선택하면 그 위치를 사용하며, 둘 다 비어 있으면 행·열 합계와 전체 합계를 만듭니다. 여러 합계는 한 번에 확정/취소하고 한 번에 실행 취소합니다. 화면에서는 첫 합계를 편집하며 상태 표시줄에서 대기 중인 합계 개수를 확인합니다. 선택 범위 밖의 결과 위치에 기존 데이터가 있으면 덮어쓰지 않고 안내합니다.

단일 셀의 자동 추정은 바로 위의 연속 숫자 구간을 먼저, 없으면 왼쪽을 사용합니다. 숫자가 없으면 `=SUM()`에서 직접 범위를 지정합니다. Excel의 모든 빈 행/소계/필터 추정 규칙을 구현한 것은 아니므로 점선으로 제안 범위를 확인하세요. 일반 `SUM`은 필터로 감춘 행도 포함합니다.

## 함께 보완한 수식 편집

| 동작 | 0.4.1 변경 |
|---|---|
| 수식 참조 표시 | 편집 중 A1 참조와 범위를 참조별 색상의 점선으로 표시. 문자열·함수 이름은 참조로 잘못 표시하지 않음 |
| 셀 클릭·드래그 | 참조를 입력할 위치 또는 현재 참조에 셀/범위를 삽입·교체. 원래 수식 셀을 유지 |
| 다른 시트 클릭 | 참조 지정 중 시트를 바꾸고 범위를 선택할 수 있음. 확정/취소 시 원래 시트·필터·스크롤 위치로 복귀 |
| 키보드 참조 | 입력/범위 지정 모드에서 방향키·Shift+방향키로 참조 지정. F2로 문자 편집/범위 지정 전환 |
| 상대·절대 참조 | F4 또는 Mac Command+T: `A1 → $A$1 → A$1 → $A1 → A1` |
| 자동 합계 단축키 | Windows Alt+=, Mac Command+Shift+T |
| 수식 입력줄 | Enter·Tab 확정, Shift+Enter/Tab 역방향 이동, Esc 취소를 셀 편집기와 동일하게 처리 |
| 닫는 괄호 | 입력한 수식의 닫는 괄호가 생략되면 최대 32개까지 보완. 문자열 내부 괄호는 제외 |
| 확대·스크롤 | 현재 배율과 행/열 크기를 반영하고 테두리가 머리글 영역에 겹치지 않게 자름 |
| 잘못된 주소 | 이름 상자의 유효하지 않은 범위 끝점이나 세 개 이상의 주소를 거부 |

기본 흐름은 Microsoft의 [자동 합계 사용법](https://support.microsoft.com/en-US/Excel/use-autosum-to-sum-numbers-in-excel), [셀 참조 사용법](https://support.microsoft.com/en-us/excel/use-cell-references-in-a-formula), [수식 입력 팁](https://support.microsoft.com/en-us/excel/formula-tips-and-tricks)을 기준으로 점검했습니다.

## 추가 점검에서 확인한 남은 차이

소스의 리본 명령, 편집·선택·저장·인쇄 경로와 기존 UI 검사를 살폈습니다. Excel의 모든 명령을 전수 비교한 결과는 아닙니다. 다음은 현재도 구현 범위가 제한되어 있는 항목입니다.

| 항목 | 현재 상태 |
|---|---|
| 함수 자동 완성·인수 도움말 | **0.5.0에서 추가**: 379개 함수 검색·범주·구문·예시, ↑↓/Tab 자동 완성과 현재 인수 표시. [함수 안내](FUNCTIONS.md) |
| 전체 열/행·구조화 참조 | `A:A`, `1:1`, Excel 표의 구조화 참조, 동적 배열/스필 미지원. 새 테두리는 일반 A1 참조를 대상으로 함 |
| 참조 테두리 직접 이동/크기 조절 | 테두리를 끄는 기능은 없음. 셀을 다시 클릭·드래그하거나 수식의 주소를 편집해 변경 |
| 복사/잘라내기 표시 | 내부 클립보드와 상대 수식 붙여넣기는 지원하지만 원본 범위의 움직이는 복사 테두리는 없음 |
| 틀 고정·분할 창 | 미구현 |
| 고급 수식 작업 | Ctrl+Enter 범위 채우기, 이름 관리자, 선행/종속 셀 추적, 수식 단계별 계산 UI 미구현 |
| 표·필터·조건부 서식 | 표는 셀 서식, 필터는 텍스트 조건, 조건부 서식은 현재 값에 색을 적용하는 수준 |
| 인쇄/PDF | 현재 시트의 셀 표를 출력. 차트·병합·전체 서식과 페이지 나누기/인쇄 영역을 완전히 재현하지 않음 |
| 차트·피벗·VBA | [차트](CHARTS.md), [피벗](PIVOT.md), [VBA](VBA.md)에 기록한 한계가 남음 |
| macOS | 공통 코드와 패키지 검사에 포함했으나 실제 Mac 실행은 아직 미검증 |

실행한 검사와 배포 파일 해시는 [검증 기록](../VALIDATION.md)을 참조하세요.
