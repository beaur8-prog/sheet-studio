# Excel 표 — 0.7.29 개발

셀 테두리로 그린 표와 Excel의 이름 있는 **Table**을 구분합니다. 0.7.29에서는 Table의 열·계산식·요약 행·필터·스타일을 유지하고 편집합니다. 현재 공개 0.7.28에는 이번 표 편집 기능이 포함되지 않습니다.

## 만들고 관리하기

1. 제목과 자료를 입력하고 자료 안의 셀 또는 범위를 선택합니다.
2. **홈 → 표 서식** 또는 편집 중이 아닐 때 **Ctrl/⌘+T**를 누릅니다.
3. 범위와 머리글 여부를 확인하고 이름을 지정합니다. 머리글은 빈 이름이나 중복 이름을 자동으로 정리합니다.
4. 만들어진 표 안을 선택하면 표 이름·범위와 **표 관리 / 계산 열**이 표시됩니다.

표 관리는 이름·마지막 행·줄무늬/첫 열/마지막 열·스타일과 요약 행을 조정합니다. 기본 초록·파랑·회색 프리셋과 가져온 사용자 스타일을 지원합니다. 셀에 직접 지정한 서식이 표 표시보다 우선합니다. 겹치는 표·병합·저장 배열과 충돌하는 범위는 적용하지 않습니다.

기존 표의 이름이나 머리글을 바꾸면 같은 문서의 셀 수식·표 수식·이름 정의·지원 차트 참조를 함께 바꿉니다. 열을 삭제하면 해당 열 참조는 #REF!이 됩니다. 여러 행/열 삽입·삭제는 표 범위·열 ID·계산식·요약·필터에도 반영합니다.

## 계산 열과 요약

예를 들어 `Sales`에 `수량`, `단가`, `금액` 열을 만들고 **계산 열**에서 금액 열에 `=[@수량]*[@단가]`를 적용하면 데이터 행마다 계산됩니다. 이 명령은 선택한 열의 기존 데이터 전체를 바꾸므로 적용 대상 행 수와 수식을 확인하세요.

자료가 비어 있는 열에 수식을 처음 직접 입력하면 다른 빈 데이터 행도 계산 열로 채웁니다. 기존 예외값이 있는 열을 자동으로 덮어쓰지는 않습니다. 새로 늘어난 행에는 계산 열의 수식과 인접 서식을 이어서 적용합니다.

표 관리에서 **요약 행**을 켜면 열별 합계·개수·평균·최솟값·최댓값 등을 지정할 수 있습니다. 지원 함수는 SUBTOTAL을 사용하여 필터로 숨긴 행을 제외합니다. 요약 행 아래에 다른 데이터가 있어 옮길 수 없으면 적용 전에 안내합니다.

요약 행이 없는 표 바로 아래에 연속된 자료를 입력하거나 붙이면 세로로 확장합니다. 다른 표·병합·배열과 충돌하거나 한 번의 편집 한도를 넘으면 자동 확장하지 않습니다. 가로 확장과 모든 Excel Table 자동 동작까지 구현한 것은 아닙니다.

## 구조화 참조

| 수식/참조 | 의미 |
|---|---|
| `=SUM(Sales[금액])` | 금액 데이터 열의 합계 |
| `=[@수량]*[@단가]` | 현재 데이터 행의 두 값 곱 |
| `Sales[[수량]:[금액]]` | 이어지는 데이터 열들 |
| `Sales[#Headers]` | 머리글 |
| `Sales[#Totals]` | 요약 행 |
| `Sales[#All]` | 머리글·데이터·요약을 포함한 표 |

대괄호·공백·특수 문자가 들어간 열 이름의 이스케이프와 일부 비연속 선택도 해석합니다. 표 이름과 열 이름은 대소문자를 구분하지 않습니다. 참조할 행이나 열이 없어지면 #REF!으로 안내하며 원본 수식을 임의의 값으로 고치지 않습니다.

XLSX 저장에서는 표 안의 암시적 참조에 표 이름을 넣고 `@`를 명시적인 `#This Row` 표기로 정규화합니다. 예를 들어 `=[@수량]`은 파일에서 `=Sales[[#This Row],[수량]]`으로 저장될 수 있습니다. 같은 참조이며 앱에서 두 표기를 모두 계산합니다.

## 정렬·필터·차트

표 안의 한 셀에서 정렬하면 데이터 행만 정렬하고 요약 행은 움직이지 않습니다. 표별 필터를 유지하며 값·숫자/텍스트/날짜·채우기색·글자색 조건을 사용할 수 있습니다. 단일 셀에서 차트를 삽입하면 표의 자료 범위를 제안하고 요약 행은 제외합니다.

일반 범위의 정렬에서도 인접한 다른 자료를 한꺼번에 정렬하지 않도록 현재 자료 구간을 추론합니다. 일부 열만 선택했거나 머리글이 모호하면 적용할 범위를 확인합니다.

## 일반 범위로 변환

표 관리의 **일반 범위로 변환**은 지원하는 구조화 참조를 현재 A1 수식으로 바꾸고 표시 서식을 셀에 남깁니다. 다른 시트의 수식·이름 정의·필터 상태도 처리합니다. 작업 스레드의 복제본에서 검증한 뒤 한 번에 적용하며 실행 취소할 수 있습니다.

한 번에 변환하거나 계산 열을 채우는 작업은 최대 100,000셀이고 문서 전체 기록 셀은 최대 1,000,000개입니다. 외부 데이터에 연결된 표, 보호된 시트와 VBA를 보존하는 XLSM의 표 구성 변경은 Excel 또는 XLSX 사본을 사용하세요. 외부 연결 정보는 XLSX에 보존하지만 앱에서 연결 자료를 새로 고치지는 않습니다.

가져오기·편집·정렬·구조 변경·필터·차트·변환·실행 취소·저장/재열기 검사는 [작업 기록](EXCEL-IMPROVEMENTS.md)에 있습니다. 실제 Microsoft Excel 실행 검증을 이번 작업에서 새로 수행한 것은 아닙니다.
