# 워크시트 편집과 보기

설치된 한국어 Excel의 홈·보기 리본과 틀 고정 메뉴를 관찰하고, 별도 시험 통합 문서에서 실제 Excel의 파일 열기·서식 재계산·붙여넣기 결과를 비교했습니다. Microsoft 원본 코드나 리소스를 가져오지 않은 독립 구현입니다.

## 셀 안에서 직접 편집

셀을 **더블클릭**하면 셀 안에 입력 커서가 나타납니다. 일반 텍스트는 클릭한 글자 위치부터 수정하며, 숫자 표시 형식이나 수식 결과와 원래 내용이 다르면 원래 내용의 끝에 커서를 둡니다. 선택한 셀에서 **F2**를 눌러도 기존 내용을 편집합니다. 셀 선택 후 바로 글자를 입력하면 새 내용으로 바꿉니다.

입력창은 셀의 글꼴·크기·색과 병합 영역 크기를 따릅니다. 커서를 옮겨 글자를 삽입하거나 삭제할 수 있으며, **Enter**로 확정하고 아래로, **Tab**으로 확정하고 오른쪽으로 이동합니다. **Esc**는 편집을 취소합니다. 위쪽 수식 입력줄과 편집 내용이 함께 갱신됩니다.

## 채우기와 글자색

**홈 → 채우기 색 / 글꼴 색** 또는 **우클릭 → 채우기 색 / 글꼴 색**에서 대상 범위를 확인하고 색을 선택한 뒤 **적용**을 누릅니다. **취소**하면 기존 색을 유지합니다. 여러 셀을 선택한 상태로 팔레트를 열 수 있으며 한 번의 실행 취소로 되돌립니다.

## 셀 서식 (0.7.9, 미배포)

범위를 선택한 뒤 **우클릭 → 셀 서식…**, **홈 → 서식 → 셀 서식…**, **⌘1(Mac) / Ctrl+1(Windows·Linux)**로 엽니다. 홈의 **테두리** 버튼도 같은 창의 테두리 탭을 엽니다. 표시 형식·맞춤·글꼴·테두리·채우기를 설정하고 **적용**을 누릅니다. 변경한 항목만 선택 범위에 적용하므로 서로 다른 기존 서식은 유지됩니다. 취소·Esc는 적용하지 않으며 한 번의 실행 취소로 모든 변경을 되돌립니다.

테두리는 **없음·윤곽선·안쪽·모든 테두리**와 위·아래·왼쪽·오른쪽·안쪽 가로·안쪽 세로를 지원합니다. 선 종류와 색을 고른 뒤 필요한 위치를 선택하세요. 윤곽선과 안쪽 미리 설정은 나머지 기존 선을 유지합니다. 미리보기에서 선을 확인한 뒤 적용합니다. 병합 셀은 전체 병합 영역의 테두리를 처리하며 숨겨진 행·열과 병합 내부 셀은 편집하지 않습니다.

각 변의 선 종류·색을 JSON과 XLSX에 저장하고 복원합니다. 기존 전체 테두리 형식도 계속 읽습니다. Windows Excel을 통한 XLSM 저장 계획과 유효성 검사를 추가했으며 실제 Windows Excel 실행 검증은 이번 수정에 포함하지 않았습니다.

우클릭 메뉴는 다른 셀 선택, 바깥 클릭, 스크롤, Esc, 창 전환 때 닫힙니다.

검증: 단위 테스트 114개 통과·Windows 전용 1개 건너뜀. Mac arm64 Electron에서 메뉴 닫힘, 셀 서식 적용·취소, 실행 취소·재실행, 병합·숨김 범위를 확인했습니다. JSON/XLSX 왕복 검사에는 값이 없는 셀의 테두리도 포함합니다.

## 틀 고정

**보기 → 틀 고정**에서 현재 셀 위의 행과 왼쪽 열, 첫 행 또는 첫 열을 고정합니다. 같은 메뉴에서 해제합니다. 스크롤, 확대/축소, 셀 선택·편집, 수식 참조 테두리에 고정 영역을 반영합니다. 시트마다 설정을 저장하며 JSON·XLSX·Windows Excel을 통한 XLSM 저장에 포함됩니다.

고정 영역이 화면을 거의 모두 차지하거나 병합 셀을 가로지르는 새 고정 위치는 안내하고 적용하지 않습니다. 분할 창, 여러 창, 고정 경계를 가로지르는 가져온 병합 셀·차트의 Excel 전체 표시 규칙은 지원하지 않습니다.

## 복사와 입력

- 복사·잘라내기 원본에 움직이는 점선을 표시합니다. **Esc**로 복사 상태를 취소합니다. 운영체제의 동작 줄이기 설정에서는 점선을 정지시킵니다.
- **홈 → 선택하여 붙여넣기**, **Ctrl+Alt+V / Ctrl+Shift+V**: 모두·값·수식·서식, 행/열 바꿈, 빈 셀 건너뛰기, 숫자 더하기·빼기·곱하기·나누기. Mac에서는 Ctrl 대신 Command를 사용합니다.
- 선택하여 붙여넣기는 앱에서 복사한 셀을 사용합니다. 값은 복사 시점의 계산 결과이며 숫자처럼 보이는 텍스트를 보존합니다. 수식만·값만 붙이면 대상의 기존 서식을 유지합니다. 서식만 붙이면 대상 값과 수식을 유지합니다.
- 대상 선택이 원본 크기의 정수배이면 원본 패턴을 반복합니다. 수식의 상대·절대 참조를 반영합니다. 한 번의 실행 취소로 되돌립니다.
- 선택 범위에서 입력 중 **Ctrl+Enter / Command+Enter**를 누르면 모든 셀에 입력하고 범위를 유지합니다. 수식의 상대 참조는 셀 위치에 맞게 바뀝니다.
- **Ctrl+D / Command+D**는 아래로, **Ctrl+R / Command+R**은 오른쪽으로 채웁니다.

잘라내기에는 선택하여 붙여넣기를 적용하지 않습니다. 붙여넣기는 최대 100,000셀입니다. 잘라내기는 셀 수식·조건부 수식·차트 이름 참조와 병합 영역을 이동합니다. 숨김 셀이 포함된 비연속 잘라내기는 차단합니다. 외부 앱의 HTML 클립보드 복제는 포함하지 않습니다. 숫자가 아닌 셀의 연산 붙여넣기는 적용 전에 거부합니다.

## 행과 열

**마우스로 크기 조절:** 위쪽 **A·B·C 열 머리글 사이의 경계**에 마우스를 올리면 좌우 조절 커서가, 왼쪽 **1·2·3 행 번호 사이의 경계**에 올리면 상하 조절 커서가 나타납니다. 경계를 누른 채 끌면 열 너비·행 높이가 즉시 바뀌고 점선과 현재 크기(px)가 표시됩니다. 마우스를 놓으면 저장하며 **Esc**로 조절을 취소합니다. 경계를 두 번 클릭하면 내용에 맞게 자동으로 조절합니다.

한 번의 드래그는 실행 취소 한 번으로 되돌립니다. 단순 클릭이나 크기를 바꿨다가 원래 위치로 돌아온 드래그는 실행 취소 기록을 추가하지 않습니다. 확대/축소, 스크롤 및 틀 고정 상태에서도 사용합니다.

**홈 → 서식** 또는 격자의 오른쪽 클릭 메뉴에서 행·열 숨기기와 숨기기 취소를 선택합니다. 숨긴 행·열을 포함한 범위를 이름 상자에 입력하면 해제할 수 있습니다. 예: `A1:C10`. 숨기기 전 크기는 JSON에 보존하고 복원합니다. 키보드 이동은 숨긴 행·열을 건너뜁니다.

행 높이·열 너비 자동 맞춤을 메뉴나 머리글 경계 더블 클릭으로 사용합니다. 글꼴과 표시 문자열을 측정하는 근사치이며 최대 1,000px입니다. Excel의 모든 글꼴·병합·인쇄 크기 계산과 같지는 않습니다. 숨김과 크기는 XLSX/XLSM에도 반영합니다.

## 조건부 서식

**홈 → 조건부 서식**은 규칙 관리 창을 엽니다. 새 규칙에서 범위, 조건, 채우기·글자 색을 정합니다. 값·참조 수식이 바뀌면 표시를 다시 계산하며 원래 셀 서식은 덮어쓰지 않습니다.

지원 조건은 숫자/값 비교(같음·다름·대소·사이), 텍스트 포함, 중복·고유 값, 상위·하위 항목/백분율, 평균 초과·미만, 참/거짓 수식입니다. 위쪽 규칙에 우선권이 있으며 **참이면 다음 규칙 중지**를 지원합니다. 규칙 편집·위로 이동·삭제·모두 지우기와 실행 취소가 가능합니다. 시트당 200개 규칙, 규칙 범위당 100,000셀로 제한합니다.

일반 A1 범위와 현재 지원하는 함수 계산기를 사용합니다. 수식은 적용 범위의 왼쪽 위 셀 기준이며 `$B2` 같은 혼합 참조를 지원합니다. 서식의 색·굵게·기울임은 읽고 저장할 수 있으며 새 규칙 UI는 채우기·글자 색을 제공합니다. XLSX에는 실제 조건부 서식 규칙을 기록하고, XLSM은 별도 Excel 작업 사본에 적용합니다. 텍스트·중복·상위/하위·평균 규칙은 저장 시 동등한 수식 규칙으로 변환합니다.

색조·데이터 막대·아이콘 집합·표준편차/테마/외부 연결 등 모든 Excel 규칙을 지원하지 않습니다. 감지된 미지원 규칙이 있으면 XLSX 내보내기를 멈추며, 원본 XLSM을 유지하거나 규칙 관리에서 모두 지운 후 저장할 수 있습니다. 임의 파일의 모든 미지원 서식 세부 사항을 무손실로 보존한다는 뜻은 아닙니다. 날짜·전체 열·구조화 참조 및 수식 엔진 제한은 그대로 적용됩니다.

- `tests/ui-worksheet.mjs`: 실제 Electron의 스크롤·고정 셀 클릭, 고정 해제/변경, Ctrl+Enter와 실행 취소, 선택하여 붙여넣기, 점선/Esc, 숨김·키보드 이동, 조건부 규칙 생성과 재시작.
- `scripts/worksheet-native-smoke.mjs`: Excel 16.0 build 19127에서 XLSX 틀 고정·숨김·조건부 색상 및 값 수정 후 재계산을 대조. 전치 붙여넣기와 상대 수식 범위 입력도 비교. 별도 XLSM 사본에 설정 적용·해제 후 다시 읽기. 매크로를 실행하지 않으며 원본 파일 불변을 확인.
- Mac 공통 코드와 패키지 검사 경로를 추가했지만 실제 macOS 실행은 아직 미검증입니다.

## 0.7.8 감사 반영 (미배포)

- 범위 편집·복사·붙여넣기·채우기는 필터 또는 수동 숨김 행·열을 보호합니다. 병합 셀 일부에 붙여넣기와 병합 범위를 포함한 정렬은 차단합니다. 병합 복사는 연속된 범위에서 원래 방향으로 지원합니다.
- 전치 붙여넣기는 상대 축과 혼합 참조 잠금을 바꿉니다. 채우기 핸들은 선택한 사각형의 원본 패턴을 반복합니다.
- 행·열 삽입·삭제는 선택 개수만큼 실행하고 한 번에 실행 취소합니다 (한 번에 최대 10,000개).
- 피벗 원본 시트나 데이터 행이 사라져 재계산할 수 없으면 XLSX 내보내기에서 마지막 피벗 결과를 일반 셀로 보존합니다. 앱 문서의 피벗 설정은 남아 있어 원본을 다시 지정할 수 있습니다.
- XLSX의 숨김 행을 필터와 수동 숨김으로 구분해 복원합니다. Sheet Studio가 저장한 파일은 수동 숨김 메타데이터를 포함합니다. 외부 파일의 지원 필터는 조건을 재계산해 구분하며, 외부 파일의 미지원 필터는 완전한 분류가 제한됩니다.
- 실제 Excel 재실행 결과를 이번 수정의 검증 결과로 주장하지 않습니다. 항목별 코드 및 회귀 결과는 [감사 처리 내역](../excel-parity-audit/06-RESOLUTION.md)에 기록합니다.
