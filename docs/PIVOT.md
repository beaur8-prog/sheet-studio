# 피벗테이블

머리글을 포함한 범위를 선택하고 **삽입 → 피벗테이블**을 누릅니다. 첫 행에는 비어 있지 않은 고유한 필드명이 필요합니다. 셀 하나만 선택한 경우 시트의 사용 영역을 제안하므로, 제목이나 별도 합계 행이 있다면 원본 범위를 조정하세요.

행·열 영역에 필드를 추가하고 값 영역에서 집계할 필드와 방식을 선택합니다. 여러 필드를 추가한 순서대로 분류합니다. **합계, 개수, 숫자 개수, 평균, 최솟값, 최댓값**을 지원합니다. 필터 항목은 Ctrl/Shift로 여러 개 선택할 수 있습니다. 미리 보기에서 결과를 확인하고 만들기를 누르면 별도 시트에 결과가 생성됩니다.

결과 시트 위의 **필드 편집**, **새로 고침**, **원본 보기**를 사용합니다. **데이터 → 모두 새로 고침**은 모든 피벗을 갱신하며, 하나라도 계산에 실패하면 기존 결과를 모두 유지합니다. 원본의 행·열 삽입과 삭제는 참조 범위를 조정합니다. 범위 밖에 새 행을 입력한 경우에는 필드 편집에서 범위를 확장하세요. 원본의 필드명을 바꾸거나 원본 시트를 삭제했다면 설정을 다시 지정해야 합니다.

결과 값은 직접 수정할 수 없습니다. **일반 범위로 변환**하면 현재 값을 유지한 채 편집 가능한 셀로 바뀝니다. 피벗 생성·수정·새로 고침·변환은 실행 취소할 수 있습니다. 0.7.38 개발 버전의 **새로 고침 시 셀 서식·크기 유지**는 기본으로 켜져 있습니다. 항목·머리글에 맞춰 색·숫자 형식·행 높이·열 너비를 유지하며 옵션을 끄면 기본 서식과 크기로 돌아갑니다. 삭제된 항목의 메모가 새 결과와 겹치는 경우에는 기존 결과를 유지하고 메모 이동을 안내합니다.

## 집계 규칙

- 합계·평균·최솟값·최댓값·숫자 개수는 숫자만 집계합니다. 숫자처럼 보이는 텍스트와 논리 값은 숫자로 변환하지 않습니다.
- 개수는 빈 값이 아닌 숫자·텍스트·논리 값을 셉니다. 완전히 빈 원본 행은 제외합니다.
- 평균의 총합계는 원본 숫자 전체의 평균입니다. 하위 평균들을 다시 평균 내지 않습니다.
- 빈 분류 값은 `(비어 있음)`으로 표시합니다. 서로 다른 데이터 타입은 별도 그룹으로 유지하며 문자열은 대소문자를 구분합니다. Excel의 그룹 처리와 차이가 날 수 있습니다.
- 0.7.31 개발 버전은 배열에서 생성한 머리글과 결과 셀도 원본에 포함합니다. 원본 읽기·미리 보기·적용·새로 고침은 작업 스레드에서 계산하므로 원본이 화면 밖에 있어도 필드를 잃지 않습니다.
- 원본 수식은 앱의 계산 엔진으로 평가합니다. 계산 오류나 지원되지 않는 함수가 있으면 주소와 오류를 표시하고 결과를 덮어쓰지 않습니다. `="#N/A"`라는 문자열은 실제 오류와 구분해 일반 자료로 집계합니다.
- 원본·결과 각각 최대 100,000셀, 행·열 필드 각각 8개, 값·필터 각각 16개입니다. 0.7.17 소스에서는 문서 전체의 1,000,000셀 제한도 적용합니다.

## 저장과 Excel 교환

| 형식 | 보존하는 내용 |
| --- | --- |
| 앱 자동 저장 / `.sheet.json` | 원본, 결과, 편집 가능한 피벗 설정 |
| `.xlsx` | 원본, 최신 결과, 앱 설정, Excel 네이티브 PivotTable 및 캐시 |
| `.xlsm` 보존 저장 | 기존 VBA/Excel 개체, 결과 셀, 앱 설정. 앱에서 새로 만든 피벗은 이 경로에서 Excel 네이티브 PivotTable로 생성하지 않음 |
| `.csv` / `.tsv` | 현재 시트의 표시 값만 저장 |

XLSX 저장은 사본에서 피벗을 다시 계산합니다. Excel에서 네이티브 필드 목록을 사용하거나 **피벗테이블 새로 고침**을 실행할 수 있습니다. Excel 새로 고침 후에는 머리글 배치와 빈 교차 셀 표시가 Excel 방식으로 바뀝니다. 조건에 맞는 행이 0개인 피벗은 잘못된 필터 결과가 생기지 않도록 결과 셀과 앱 설정만 XLSX에 저장합니다.

앱 설정은 독립적인 Custom XML에 저장됩니다. 0.7.38 개발 버전은 네이티브 필드·배치·필터가 앱 설정과 일치하는지 먼저 확인합니다. 다르거나 결과 바깥에 셀이 추가된 경우 저장된 결과와 기본 원본 피벗의 정의·캐시·연결을 유지하며 이전 앱 설정으로 재계산하지 않습니다. 앱에서 만들지 않은 기본 Excel 피벗도 같은 보존 경로를 사용합니다. **Excel에서 바꾼 설정을 앱 필드 편집기로 역변환하는 기능은 아직 없습니다.** 시트 이름 변경 등으로 앱 설정을 연결할 수 없는 경우에도 원본 피벗 보존을 우선합니다. 기존 XLSM의 원래 피벗 개체는 Excel 보존 경로를 따릅니다.

보존 중인 피벗은 안내 막대에 **Excel 피벗 원본 보존**으로 표시합니다. 해당 결과 범위의 값은 잠그고 다른 셀의 값·서식은 편집할 수 있습니다. 행·열·시트·표 구성 변경은 연결 보호를 위해 제한합니다. **일반 범위로 변환**을 명시적으로 선택하면 원본 개체를 제거하고 저장된 결과를 편집하며 실행 취소로 되돌릴 수 있습니다. 외부/OLAP·슬라이서·사용자 지정 피벗 스타일 등 일부 고급 피벗 서식이 연결된 경우 XLSX 보존 저장은 거부하며, Excel 저장·앱 문서·일반 범위 사본을 안내합니다. 다른 미지원 기능은 **도움말 → 파일 호환성**에서 확인합니다.

날짜 자동 그룹, 중간 소계, 계산 필드, 값 표시 형식(% of total), 고유 개수, 슬라이서, 드릴다운, 외부 데이터/OLAP/Data Model 피벗은 아직 지원하지 않습니다.

구현은 [Microsoft의 SpreadsheetML 피벗 구조 설명](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-pivottables)과 자체 생성한 Excel 테스트 파일을 기준으로 검증했습니다. Microsoft 코드나 추출한 제품 리소스는 포함하지 않습니다.

0행 결과처럼 네이티브 피벗이 없는 파일은 정적 셀과 앱 설정을 비교합니다. 외부에서 결과나 추가 셀을 변경했다면 기존 셀을 유지하고 **정적 피벗 결과 유지**를 표시합니다. 이 셀은 일반 셀로 편집·저장할 수 있으며 새 피벗은 원본 자료에서 다시 만듭니다.
